B. 与作者 HotpotQA 实现的区别
核查官方源码：https://github.com/ysymyth/ReAct/blob/master/hotpotqa.ipynb
作者版本使用 6 个例子、编号 Thought/Action、在 Observation 前停止生成，并在 Thought/Action 解析失败时追加一次只生成 Action 的调用；主循环最多 7 个动作机会。工具是 Wikipedia Search/Lookup/Finish。
本地版本使用 3 个 HotpotQA 训练例子、不编号的 Thought/Action，一次生成最多 512 token，没有 API stop 参数，也没有补动作恢复。工具是统一 BGE 语料 Top-10 Search/Finish，不提供 Wiki Lookup；最多 5 次实际 Search 和随后一次 Finish 机会。提示没有声明当前剩余搜索数。
