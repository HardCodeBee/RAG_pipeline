# 第三轮：与真实失效案例逐项对照

本表是设计覆盖检查。没有把r03发给模型，不能将“希望发生”写成“已经修复”。全部真实案例仅用于本地诊断，未复制进入虚构few-shot。

| 已有观察 | r03中对应设计 | 仍然可能失败的位置 |
|---|---|---|
| 刘娥配偶之父被答为刘娥自己的父亲；已有reader有正确关系 | ordinary同时保留原始当前问题、候选检索措辞与历史；family示例示范沿配偶再沿父亲 | 错误检索措辞仍可锚定模型，示例不保证实际执行；新增普通样本此前无最终变化 |
| Richard II的局部完整关系句修复后最终答案未变；分解相对原题多走一代 | ordinary忠实回答当前子问并保留关系深度；goal重新对准原题，不复制最后子答 | goal能否在现有材料中补回正确代际未知；不靠偷偷改分解掩盖问题 |
| 运河题缺精确经度，综合段落曾利用相对位置答对；追加许可仍可能无效 | goal替代求解路径示例，用明确的相对东西关系演示充分性 | 真实地理材料可能没有虚构示例那么强的整体顺序条件，不能把任意两个州名当成充分证明 |
| Shirley Temple仍被擅自按“最高级别”挑职位 | goal保留符合所问的多个职位；final示例从错误prestige筛选中恢复其他职位 | 新示例可能过度扩展所有列举题；必须保留问题本身的first/latest等限制 |
| Chadwick保留两个项目有局部F1收益，通用final提醒没有同样效果 | goal Facts与Candidate保留符合关系的必要候选，final读取全文 | 多列真实但不响应问题的项目会降质量；不能把“越多越好”当原则 |
| 篮球家庭QA矛盾被综合段落重新包装成结论，F1同为0隐藏退步 | 处理实体/角色冲突，不把“保留先前事实”写成无条件服从 | 没有独立证据时无法确定哪个家庭是真正目标；稳健弃答不等于提高F1 |
| Antelope物种的俗名与科学名、Geordie配偶的撇号产生原生计分差异 | final保留识别所需名称；复核单列实体不变的评分变化 | 未设计按标准答案清洗器，也不承诺最短答案自动等于最佳原生匹配 |
| HotpotQA7正确电影在候选中但被合并Top10筛掉 | 本稿保持检索/合并以免混淆效应 | prompt不能使用被移除的证据；需要独立reader选择实验 |
| 国籍被问成出生地等局部数据集关系冲突 | 所问关系保持一致，资料不足不偷换属性 | 原生零分保留，数据集问题单列，不能算作候选提示已解决 |
