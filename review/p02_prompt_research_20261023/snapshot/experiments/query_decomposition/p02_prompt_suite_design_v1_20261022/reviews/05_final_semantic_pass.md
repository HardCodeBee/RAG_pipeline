# 第五轮：充分性、完整性与对照定义

本轮重新检查40个合成场景的人工预期，重点找“看似合理但材料不足”的地方。这里是人工设计复核，不是对模型的盲测。

实际发现C37的材料只给出Pera于1980年任市长、1990年任大使，不足以确定1980年是其第一份公职：还可能有未列出的更早职位。这与不完整列表不能代表全集是同一个问题。当前材料已明确写为“first public post was mayor”；原始弱证据保留在CHALLENGES.first_draft.json，不删除此前版本。

其余重点边界复核：

- C01：parent不能独自推出father；普通实体名字不提供性别或角色证明。
- C03/C30/C31：当前子问与原题可以有不同代际，ordinary不能暗改当前问题，goal不能自动继承错误深度。
- C14/C15/C16：AND中假已足够否定、OR中真已足够肯定，而AND中仅真＋未知仍不足。
- C17/C18/C20：部分列表的下界有时足够比较、有时不够；全赛事头衔与全国冠军不是同一统计口径。
- C21/C33：相等应保留平局；数值比较前单位必须一致。
- C22：虚构案例明确所有相关区域的东西顺序，不能外推为任意地域名称都足以比较。
- C25/C29/C40：先前答案和goal新事实可以使用，但没有新段落确认时不得虚构“段落证实”；没有独立验证不等于一律删除中间信息。
- C27：响应所问的真实部分列表可保留；不能将未列全自动改标为事实错误。
- C34/C38/C39：同一实体跨年份不同不等于冲突；同scope不可解释冲突也不能靠平均或顺序解决。
- C36/C37：缩短答案不能删掉必要消歧词；保留多个事实不能无视原题的first限定。

同时核实了后续实验中的历史H与同期B00定义：共同额度、响应完整性与新字段都是可影响结果的因素。历史native允许final截断，故新完整stop控制不直接等同历史轨迹。已在验证计划中明确，无需通过改写旧结果来制造一致。

本次的三轮实际模板r01/r02/r03保留；后两轮审核主要校正挑战集和验证解释，没有为了增加修订次数而另造一套模板。
