# 历史错误复核与 r04 修正依据

本轮由用户“回顾错误历史 认真的进行修正”授权。只处理本侧对话的独立提示词研究，不操作主线程的运行任务或正式评估。2026-10-23，Australia/Sydney。

## 先纠正研究过程中的判断

1. **格式适配不等于能力提升。** 原 `#N` 指令本身仍可指导模型利用带编号的完整 QA；现有描述式问题不一定导致模型无法绑定实体。r03 预选18个普通节点中，新旧主要答案全部相同；不能再以“原格式不匹配”为充分理由整体替换。
2. **小挑战集收益不能替代全组结果。** scope27 中 S2 对 S0 的 F1 差为 +5.56 点；另一项原生90题 ROLE 变体只有 −0.56 点。二者版本与样本不同，不能用挑战集证明普遍收益。
3. **更长的推理不等于正确组合。** r03 新 goal 明确执行了 Facts/Link/Candidate 格式，但仍产生错误年代推断、关系层级误读及额外条件。旧 final 下 F1 下降7.14点，不能因为输出“像推理”就视为机制修复。
4. **规则补丁也必须有对照。** 既有 retention60：替代路径 −0.67点、候选保留 −0.43点、final 保留提示 0点。target_transfer60：目标规则及四示例 −0.50点，短综合 +0.79点，文本包装 +0.24点；均没有稳定大幅收益。故本轮不继续把这些规则和更多示例一起叠加。
5. **阶段成功不能冒充完整流程提升。** 固定 reader 的改进没有检验新子回答如何影响后续改写和检索。普通节点的文本改变也不等于事实修复。
6. **完整对照与记账边界。** r03 的 C 是冻结 role_headers 提示的同上限对照，不能称为原始 P02 的全流程新结果。此轮 C 使用严格相同 payload 的完整旧回执，非同时期独立重新生成；新增 S/T 的生成波动不能由此消除。

## r04 的具体范围

普通 QA 和 final 的候选决定是撤回 r03 改动，沿用旧版本；rewrite、冻结 R02/v12 分解器不变。新试验只比较 goal：

- C：旧事实句。
- S：仅替换旧输出契约为两三句“事实、必要连接、答案”。保留旧输入、纠正条件、缺失处理和组合一致性规则。
- T：在 S 上增加一个目标理解段。这个段包含相关的目标/时间/纠错规则，T−S 检验的是整个段，不是其中任意一句的单独效应。

不新增 few-shot，使本轮不会把示例变化与输出契约、目标规则混为一谈。并非认定 few-shot 无用；此前示例/操作说明实验已有混合结果，应在有依据的父版本上单独检验。也不声称 S−C 是“纯推理”效应：它同时改变可见输出长度和内容形式。

固定90题、每集30题，全部已有多轮暴露。两组 goal 上限512，final128；旧 final 完整接收新的段落，输入材料不裁剪。旧对照严格回放，本轮新增结果不覆盖历史；不因分数不理想重试。

## 约束的反例检查（人工设计检查，不是模型通过率）

- “《Blue Harbour》的作者获过什么奖”中，书名识别作者，奖不必因这本书获得；“因《Blue Harbour》获得什么奖”中，因果限制必须保留。
- “River County 所在省的位置”应先得到省再问位置；“River County 位于哪个省”只问上一级名称。两个问题不能给同一种关系回答。
- 一个校区隶属大学系统时，口语的“所属机构”可由该关系回答；若问题明确要求上市公司，则不能把大学系统充作商业公司。
- 祖父先于孙子出生去世不构成不可能；若材料说父亲出生于祖父死后很久，则是真实冲突，需要保留不确定性。禁止从省略的出生日期造出冲突。
- 识别线索未在材料中复述不等于矛盾；若材料明确显示线索指向另一个同名实体，则必须重新核对。
- 目标答案确实缺失时，两三句输出也应表达具体缺口，不能以短输出为理由强制猜答案。
