# 本轮结论与后续研究重点

本轮已完成普通 QA 的 38 个节点 × 2 组，以及固定 90 题的 goal × 3 组，共 346 条实验结果。全部成功返回，没有截断、未知请求或缺失；实际返回 usage 对应费用为 1.299408 元，账本与原始回执已核对一致。主评估仍暂停，生产实现和原 P02 冻结版本没有修改。

这是一轮冻结上游材料的开发实验：保持 R02/v12 分解、普通子回答、goal 改写和检索材料不变，只重新生成指定阶段及其 final。它不是完整 RAG 重跑，也不是独立测试集验证。以下 F1/EM 均沿用官方计分，不通过人工判断改分。

## 1. 结果

普通 QA：D 使用已有描述式示例，B 只增加两段示例说明，指出上一问的返回值是什么、它如何填入下一问。37 个可判定配对中，B 的正确性改善 0 个、退化 1 个、持平 36 个；另 1 个节点两组均保留待核。必要信息保留改善 0 个、退化 2 个、持平 35 个。38 对输出中 33 对文字完全相同。本轮不支持用这两段说明替换原方案。

Goal：G0 保留原事实句提示；GF 使用简洁综合指令和六个“事实＋结论”虚构示例；GO 在完全相同的示例事实与结论中加入必要操作说明。三组统一 512-token goal 上限、final 包装及 64-token final 上限。

GF 对 G0：8 题改善、8 题退化、74 题持平，平均 F1 下降 2.86 个百分点。GO 对 G0：6 题改善、13 题退化、71 题持平，下降 6.41 个百分点；数据集分层配对 bootstrap 的 95% 区间为 [-11.50, -1.92]。GO 对 GF 的点估计下降 3.55，但区间 [-8.11, 0.46] 包含零，不能据此把差异当作普遍定律。

2Wiki 的这 30 题中 GF 有局部回升：94.13，高于共同协议 G0 的 92.80，但仍低于历史原 P02 的 94.33；这不是正式 500 题成绩更新。三个数据集上的总体结果不支持晋升 GF 或 GO。

与上一轮 G2/I/F 在相同 86 题上重新对齐后，数据集等权 F1 为：原 P02 76.19、G0 76.13、G2 68.75、I 70.14、F 68.90、GF 73.99、GO 70.30。简洁版有所改善，但尚未达到目标。跨轮比较并非同期随机实验，不能把全部差异归因于某一条指令。

## 2. 对原因的判断

**现有证据不支持把问题主要归结为示例格式没有适配，或缺少推理文字。** 普通 QA 中增加“返回值如何使用”的说明，绝大多数输出不变；goal 中显式操作示例也没有带来总体提升。这仅否定本轮具体改动的有效性，不能证明实际输入中的 `#N`、实体替换或其他绑定方式无效。

实际输出暴露了四个值得分别处理的环节：

1. **目标和条件解析。** After Hours 题已有正确奖项，GO 却添加“必须因这部电影的表演获提名”的条件，最后弃答。正确事实进入上下文，并不能保证模型在回答原来的问题。
2. **事实的角色与语义类别。** 刘娥题中 B 将配偶的父亲刘渊替换成刘娥自己的父亲刘殷；职业交集题中 GO 明确展示了集合操作，却排除了 writer 与 screenwriter 的语义联系。先选错关系槽位或类别，再写操作解释，仍会得出错误结果。
3. **事实到候选结论、再到 final 的传递。** Golestan 题的综合段落已写出“里海南部”，但候选结论和 final 丢失了这一位置描述。问题发生在信息已经取得之后。
4. **答案表达与官方计分。** `two` 与 `2`、墓地名称是否附加城市等，会产生明显 F1/EM 差异；另有一些部分匹配分数较高的答案仍答错了所问关系。分数变化不能全部解释为推理能力变化。

另外，说明写得连贯不等于推导成立。Mitau 案例把出生地、居住地和“没有别的地点”作为死亡地的理由；即使实体与参考答案相符，这条理由仍不足以推出结论。相反，Le Rêve 案例的 goal 犹疑或表述出错，final 仍回答正确，说明应保留 final 独立读取证据的能力。

本轮 GF/GO 的平均段落长度约为 54.5/64.9 个空白分词，全部正常 stop 结束，因此这些退化不能归因于输出被截断。GO 同时增加了示例内容与长度；本轮不是严格的等长度“推理内容”因果实验。

## 3. 后续方向

本轮到此结束，未排队新的评估，未替换主方法。下一轮更有价值的独立对照应当按以下顺序准备：

1. 先检查并约束**原题目标**：输出类型、要问的关系、明确条件，以及只用于定位实体的描述。重点防止把定位描述升级为额外条件。普通 QA 与 goal 分开验证。
2. 再检查**必要事实的保留**：区分“有根据的事实条目”和“候选短答案”，让 final 同时看到两者。对照应保持事实内容一致，只改变传递形式，才能判断是否解决了信息丢失。
3. 对真实组合错误，再测试**具体操作及语义归一**。不能只示范数字比较或集合符号，还需检验关系方向、类别包含、时间范围和结果映射是否正确。
4. 候选只能在不同于反复使用的固定 90 题的新样本上确认，再考虑完整流程验证；原 P02 保持对照。新实验不得把这批已分析案例包装为独立确认集。

逐题输出、原始回执、配对统计、普通 QA 标注和 15 个代表性 goal 案例均保存在本目录。普通 QA 标注是知情的本地复核；goal 案例是事后解释性抽查，均不冒充独立人工金标或全体错误类型的频率统计。
