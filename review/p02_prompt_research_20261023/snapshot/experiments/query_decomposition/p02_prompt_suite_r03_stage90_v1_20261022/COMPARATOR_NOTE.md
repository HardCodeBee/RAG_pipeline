# 对照来源与解释边界

本轮 C 的 goal 指令来自冻结90题轨迹中的 `historical_goal_prompt`，具体来源全部为 `p02_role_headers`：pilot100中的30题、extension200中的60题，各数据集各30题。O0 同样使用这些轨迹保存的普通子回答指令。所有源文件路径和散列在 `SOURCE_BINDINGS.frozen.jsonl` 中；模型请求可从本轮checkpoint重建。

因此，报告应称 C 为“冻结 role_headers 旧 goal＋旧 final 的同上限重测”，不可简称为“原始P02完整流程基线”。H 是这些历史轨迹的已存最终答案，也不是原始P02的独立重跑。本轮 C 使用原有 final 渲染器；G 使用同一 final 渲染器；GF 使用 r03 final。所有上游问题、普通回答和检索包固定。

普通回答上限256、goal上限512、final上限128是本轮各对应组共享的上限；历史轨迹的原始上限与之不同。历史 H 仅作来源参考，选择比较以本轮 C/G/GF 为准。

这一说明不改变冻结输入、提示词、任务顺序、上限或已提交的请求。阶段试验可以回答“在这批旧上游输入上，替换goal以及final产生什么变化”，不能回答“整套r03是否优于正式P02”或“新ordinary动态传播后会怎样”。
