# r04逐例结论与下一步边界

## 结论

这次修正未成功提升质量。S F1为68.06，T为67.98，都低于旧对照76.12，也未超过前轮r03 goal＋旧final的68.98。C→S为5改善、15下降、70不变；C→T为5改善、14下降、71不变。T相对S为4改善、7下降、79不变，平均差−0.08点。不能因为T在少数旧错误上有恢复，就宣称目标规则有效或整套提示已经修好。

保持冻结的role_headers父版本作为本轮对照，S/T仅留研究记录。生产P02未变。这里不是原始P02全流程的重新评估。

## 哪些判断需要修改

**“主要是原prompt不匹配描述式分解”缺乏充分证据。** 历轮普通回答中，原模板能完成许多描述式实体绑定；新增操作说明的37个可判节点没有净改善。追加四例复核进一步发现，部分问题实际是分解语义的偏移：例如原题的出版频率变成子题的copies，或同名作品的实体选择被后续提名目标带偏。不能只把`#`换掉或增加解释就期望解决。

**“把推理显式写出就能提升组合”在当前协议下再次失败。** S仅改变旧goal输出契约，其他输入、规则、final和上限不变，F1仍降低8.07点。这个结果针对当前指令与冻结输入；C为历史精确回放，未控制独立重复生成噪声，也不能推广到所有CoT方法。不过它足以反对直接上线当前可见长解释形式。

**“补一段正确规则就能消除错误”也不成立。** T明确要求不增加时间或条件，但依然要求当前婚姻状态、当前法官、必须因《After Hours》获提名。指令的合理性与实际执行可靠性必须分别验收。

## 落实到候选方案的修正

1. 撤回r03普通QA的Support/Answer作为默认候选：它没有已证实的动态收益，且有截断、语义越界、额外证据门槛的实例。保持旧普通QA作为控制；不能把撤回描述为旧QA全面正确。
2. 撤回r03新final作为默认候选：同一goal输入曾出现新的信息丢弃。保留旧final，同时承认旧final也会选错属性。
3. 不采用r04 S/T综合段落；不再默认同时重写多个阶段。
4. 复核分别记录目标对象、目标关系、支持信息、结论、final使用情况；把“事实真”“当前材料支持”“对下一步有用”分开，不再以某一项代替其余项。
5. 修复执行记录：本轮用SQLite和追加事件观察进度，避免旧STATUS文件占用造成的中断；严格缓存、未知请求保留与费用核对不变。

## 后续研究方向，尚未执行

若继续，优先回到短事实句父版本，单独检验**目标关系的对照示例**：同样实体和材料，一题问作品识别的人的奖项，另一题明确问因该作品所得奖项；同样地对比问所属省份、问该省位置。示例只用虚构材料，不把本批真实题或答案注入请求。先确认模型能区分这些最小语义变化，再考虑加入简短说明。它仍需与父版本对照，不能因为示例写得清楚就认定有效。

另一条独立方向是固定同一goal，只研究final如何选出所问属性；它不与goal模板同时改。普通QA的原题消歧与越界问题则需要另立边界对照。本次不自动追加这些实验、重训分解器或恢复正式评估；所有完整结果先保留为下一次设计的证据。
