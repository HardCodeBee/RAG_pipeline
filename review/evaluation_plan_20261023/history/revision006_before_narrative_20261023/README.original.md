## 请审核的研究定位与取舍

用户正在重新考虑论文目标：不以证明所有场景最佳为必要条件，希望围绕明确研究问题组织方法、对照与贡献。目前尚未批准缩减九种基线，也未正式替换现行评估协议。

供讨论的主线是：**通过分解组织复杂问题的信息需求，再通过分步求解，形成最终回答可使用的事实。** 这是一条研究叙事建议；分解、迭代检索和中间答案本身已有大量前作，不能仅凭重新命名就主张新颖性。中间QA也只是需要核验的候选事实，不能预先视为可信证据。

希望远端反馈以下具体问题：

1. 该研究问题与现有P02实现、已完成结果是否吻合？贡献应如何准确限定，哪些主张当前证据不足？
2. 在固定Qwen+BGE下，哪些代表性对照足以覆盖单次检索、分解检索、分步求解和迭代检索？如建议缩减当前九基线，请说明每个保留方法检验什么问题，避免按预期输赢挑选对照。
3. 参数来源应如何统一：原论文已报告最佳、作者默认、还是后续研究完整设置？对无法给出唯一值的方法，哪些适配最有说服力？
4. 现有完整流程质量与成本评估能支持到什么结论？若要声称“事实形成或利用机制有效”，最少还需哪些独立对照？这些建议应另列范围与预算，不能把诊断相关性当因果消融。
5. 上述分母、缺失处理、复用、计时和费用条件是否足以保证解释清楚、比较公平？有哪些执行前必须补齐的事项？
