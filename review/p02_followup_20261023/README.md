## 本轮回答了什么

1. **分解形式与提示词是否匹配。** 冻结R02/v12使用自包含描述式子问题，而旧提示保留`#N`示例。本包保存自包含样式、去引用、最小改动、三prompt联改及紧凑版的完整90题恢复结果；不会把早期根目录的partial报告当最终结果。仅使格式一致没有建立总体收益。
2. **显式实体、当前问题和原题目标如何分工。** 固定节点探针、8题挑战、动态8题与balanced20区分“实际传入的子问题”和“原始目标”。部分错误可以局部修复，但有退步或技术缺失，不能把挑战集提升推广到正式集。
3. **goal如何组合已有事实。** 已运行短综合说明、组合挑战、角色／事实提示和最终目标检查。固定输入阶段实验与完整动态RAG分列；goal新增推理并不保证关系、属性、时间和集合条件正确。后续旁支few-shot、r03/r04等见已有旁支包。
4. **候选材料是否进入reader和最终答案。** 后续信息流复核覆盖270条；reader选择M4在动态8题中补全了一个日期，但扩到固定2Wiki20题后没有总体变化。不要把合理弃答或真实但不完整的回答误解为信息充分。
5. **共享上下文与普通CoT是否改善最终F1。** 共享上下文共同89题未取得收益，tokens约增加82%；普通CoT同期完整90题F1从76.47降至67.00，总tokens增加6.84%。CoT的事实字段对照也下降，不能把共同的格式、示例与证据约束影响全部归于推理本身。

## 必须保留的状态与解释边界

- 30项记录包括固定reader探针、历史精确重放、动态完整流程以及未完成实验；不是30项正式评估。不同实验复用题目，条件数不能相加当作独立样本量。
- 引用符号／绑定／优先级完整流程仍为 **61/360暂停**；对应固定节点阶段已取得152份返回，但语义复核有明确范围，不能据61条宣布90题效果。
- balanced20为 **38/40**，共享上下文为 **269/270**，普通CoT为 **359/360**。技术held保留缺失，不自动补0，不超出既定5次实际尝试重发。CoT的N128/R256主比较完整90题；四组比较用共同89题。
- 计分使用原生F1/EM。标点、真实头衔、答案长度可能改变分数；语义复核另行解释，不事后修改评分。12条CoT降分不能全部称作新增事实错误。
- 样本已用于开发或继承既有评估，缺少独立未见确认；变化案例复核也不提供总体失效率或唯一因果估计。
- tokens／逻辑费用、已返回usage估费、未知请求费用预留分别保留；未知不等于零，也不等于确认已付款。运行墙钟时间不冒充正式query纯处理时间。
- 历史文档中的`publication:false`描述当时授权。本次发布由用户最新明确指令授权，未改写旧协议。CoT原先的前置调度要求被后续优先级修订覆盖，修订见决策文件；科学设置不因调度调整而变化。

## 交付形式

`archives/`保存原仓库相对路径与源字节；`reports/`提供最终入口的原样预览；`receipts/`是实验各checkpoint的只读全表压缩导出，包含实际请求、回答、usage、状态和历史失败。JSON列保留原字符串，读取时再解析。全局账务数据库、凭据、模型权重、完整语料索引、重复运行快照和操作日志未打包。

本包支持独立离线核对材料与主要汇总，**不声称提供可直接启动付费完整RAG的运行环境**。所需大型外部依赖在[依赖说明](DEPENDENCIES.json)中记录；部分历史原始证据亦可从旧包取得，见[历史依赖对应](PUBLICATION_DELTA.json)。当前运行源码供审阅，实际历史prompt以每条请求payload为准。

## 离线核查

在本目录运行（Python 3.9或以上；不需要模型库）：

```bash
python -B verify_offline.py
```

该命令核对交付文件、全部ZIP成员和所有表导出的行数／列结构，并独立重聚合CoT和共享上下文主要F1/EM、配对变化、tokens及费用，检查引用因素61条完成记录与299条未开始计划。它不调用API、不联网、不加载模型；不声称重新完成语义标注或全部实验的原生答案字符串评分，也不重新抽样bootstrap区间。

若需沿原路径阅读材料，可先解压到一个新的空目录：

```bash
python -B extract_sources.py --output ./extracted_sources
```
