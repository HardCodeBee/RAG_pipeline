每格为正确条件／错误条件下的结果正确率；第2行的结果是后续改写，其余是最终回答。分子分母和95%区间在[机器可读统计](CONDITIONAL_PROBABILITIES.json)。最终正确始终是已有F1=1或EM=1。

## 当前解释和证据边界

goal预答与最终答案的关联最强：2Wiki为77.7%（355/457）对8.7%（2/23），HotpotQA为59.3%（127/214）对27.3%（6/22）。普通回答均正确但goal错的27题中，22题最终也错。具体案例显示错误goal可能覆盖正确中间关系，以及最终抽取选错已可见属性。因此goal一致性与最终综合是优先检查建议。

这不是因果排名：goal本身与最终都回答同一个原问题，天然更接近端点；goal错误只涉及230个既有非满分案例中的37个，不能据此声称解释了多数损失。另189例goal被判正确仍非满分，混有合理弃答、不完整桥接、别名／附加描述扣分和参考实体串接。36个选例不是对230例的穷尽归因。

分解实质语义错误仅2Wiki3题、HotpotQA9题，其余不通过项多为U冗余；不能把冗余与事实／结构错误混成一个影响。改写两组的最终正确率差值区间在两集均跨0，不能解释成错误改写有益或估计修复收益。88条改写错误中80条发生在goal；普通改写错误分别仅3、5条。

事实正确性由单一Codex审阅者离线标注，未使用独立人工金标。先冻结阶段标签并复核，再合并已有最终评分；bootstrap仅反映按query重采样的不确定性，不覆盖标签误差。没有根据本诊断修改评分器、提示词或方法。
