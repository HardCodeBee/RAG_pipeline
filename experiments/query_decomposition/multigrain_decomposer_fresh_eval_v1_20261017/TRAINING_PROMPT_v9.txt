Audit and minimally repair a candidate list of prerequisite questions against the original question. This is a question-editing task, not answer generation. The candidate is untrusted model output. Use no facts beyond the original question.

Return the corrected complete list as a JSON array of question strings. Apply these concrete checks:
1. For each item, resolve every referring expression from the original question into a full description WITHIN that item. For example, if a singer is identified as the performer of Song R, replace "that singer" with "the performer of Song R". Never insert the singer's actual name from memory. Do the same for teams, leagues, cities, states, films, relatives and other objects. Preserve all original name disambiguators and identifying conditions.
2. Delete generic identity questions about already named entities, questions asking for facts explicitly supplied in the original, and unrelated attributes. A composer lookup may help a question about the composer's place of death; the composer's birthplace or burial site does not help that request. Do not invent an extra question to replace a deleted one.
3. If the candidate merely repeats a multi-step original, add the useful missing intermediate identity question. Otherwise keep useful complementary bridge levels and operand facts. For same-country comparisons, ask which country each object is from, not whether each is in some country.
4. Repair changed relation directions, missing conditions and unsupported guesses using only the original text. Do not assume a parent's gender, one specific path for an ambiguous family relationship, a work's medium, an unstated date or a remembered surname. Keep genuinely ambiguous original wording; do not force a guessed interpretation.

The program separately retrieves and answers the original question. No special final question is required. A naturally occurring original-equivalent question may remain if it is fully self-contained, but it cannot replace useful intermediate information. Do not mechanically add or delete a final item solely by its position. If the original is already local and no useful prerequisite exists, return [].

Example:
Original question: Who is the actor in Video R by the performer of Song S?
Candidate: ["Who performs Song S?", "Who is the actor in Video R by that performer?"]
Corrected: ["Who performs Song S?", "Who is the actor in Video R by the performer of Song S?"]

Original question: What is the name for an adventure in Game R, designed by Darin?
Candidate: ["Who designed Game R?"]
Corrected: []

Output only the corrected JSON array. No answers, commentary, review labels, step IDs, goal field or Markdown fences.
