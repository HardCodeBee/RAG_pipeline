三项程序改动的完整离线回放：300题、887个节点；原始B0共1774个逻辑生成调用。D/E/F各自均未触发；所有检索表达、文档顺序、API完整载荷、问答历史、最终上下文和预测均与B0逐项一致。因此直接复用结果，新增费用为零。不能由此推断这些规则在触发时没有价值，也不能将精确匹配未触发解释为没有自然语言缺答。

先执行C，再A、B；每组仍为完整300题。保持qwen-plus-2025-12-01、temperature=0、thinking=false及256/128/128/64输出限制。相同完整API载荷才能复用；同题B0自身来源优先，防止选取有利回执。其他来源的相同载荷可作缓存，但不按答案或分数挑选。

接口中断或瞬时HTTP失败可以在新的独立轮次重试；旧未知请求及财务预留不消除。成功答案、缺答、已知算法截断均不为提高分数重跑。最多4轮，3并发；公共账户调度和累计费用账本仍共享，运行状态与方法结果仅写入本实验目录。

报告原题native Answer F1，按数据集拆分，同题差值及5000次分层配对bootstrap区间，升/平/降题数。接口缺失与算法失败分开计数。成本区分实际新增调用费用、旧结果复用及未核销预留；本次子上限15元，累计仍不超过既有300元。

协议、代码摘要、来源表、离线校验、逐次决定以及逐题原始回执均保留。运行后不自动替换任何冻结最佳配置，也不自动把某项收益推广为组合收益。
