# M6 软 BCE 蒸馏：单次正则补偿实验结果

2026-09-15。**15 次正式拟合和 3 次小试完成，独立复核通过；配方推进门、候选准备门均未通过。** 这是已消费旧 9,600 query 上的一次机制对照，没有新独立来源验证或部署结论。

## 1. 结论

按解析值将 Student 正则从 .001 降至 .0005 后，PreC 的特征系数在五折均朝原 Direct 靠近，符合此前识别的一般收缩机制。**这一参数补偿没有产生达到预定要求的 probe 特有或相对原 M6 的迁移收益。**

- ProbeC−PreC：−0.000363907，条件区间 [−0.001975948, +0.001267885]。
- ProbeC−原 Direct：−0.000386656，条件区间 [−0.002008175, +0.001199281]。
- ProbeC−DirectC：+0.000562358，条件区间 [−0.001669066, +0.002850489]。

前两项区间上界低于要求的 +0.002；**第三项上界为 +0.002850489，仍包含 +0.002，不能说它排除了该幅度。** 三项区间均跨零，不能据此认定 ProbeC 更差。ProbeC 相对 Dense 的上界低于候选要求的 +0.01。

执行决定为 `END_SINGLE_REGULARIZATION_COMPENSATION_NO_CONFIRMED_TRANSFER`：**结束这次解析补偿机制分支，不自动追加 λ、α、温度或阈值网格。** 结果约束当前 M6 线性 Student、固定目标与这次补偿值，不证明所有蒸馏无效或 query 中没有相关信息。

依据：[原始结果](../../outputs/router/hotpotqa_bd_router_v1/runs/m6_student_compensation_v1/results.json)、[独立复核](../../outputs/router/hotpotqa_bd_router_v1/runs/m6_student_compensation_v1/separate_checks.json)。原结果保留生成时的 `pending_separate_check` 状态；后续复核收据的终态为 `passed_independent_student_compensation_checks`，不修改已绑定文件。

## 2. 问题、机制与固定设计

[上一轮](m6_student_transfer_results_20260915.md)已经实际完成严格 OOF 蒸馏，但没有确认迁移。[固定产物诊断](../../outputs/router/hotpotqa_bd_router_v1/runs/m6_student_localization_v1/results.json)发现模型确实收到目标变化，而 Pre 的参数变化方向与解析收缩项接近；只在 Direct 处计算补偿梯度，也显示其残差减少。因此本轮检验一个确定的补偿值，未重新打开参数搜索。

在理想的同训练集自预测情形下，正则化 Teacher 就是 Direct。将其概率与硬标签按 α 混合，同时保持 Student 的原正则，会在 Direct 解处留下额外的 αλ[β,0] 梯度。取

$$
\lambda_{Student}=(1-\alpha)\lambda_{Teacher}=.0005
$$

可使该理想解重新成为驻点。真实 Teacher 使用 OOF 子集或 probe，不满足这个自预测条件，因此推导不保证实际参数完全恢复，更不保证答案效用提高。共同收缩项在 Probe−Pre 的目标差中消去，不能单独解释特权增量失败；所以本轮保留匹配的 DirectC 和 PreC 控制。[冻结方案](m6_student_compensation_plan_20260915.md)

| 项目 | 实际执行 |
|---|---|
| 数据与划分 | 旧 9,600 query / 9,559 group；原五折，每折 fit 6,144 / cal 1,536 / test 1,920 |
| 输入 | 三个新 Student 都只使用冻结 384D M6 FP32；不使用检索后 probe |
| 旧三臂 | Direct、Pre、Probe，λ=.001；头和预测全部保留 |
| 新三臂 | DirectC、PreC、ProbeC，λ=.0005；仅改变 Student 正则 |
| 监督 | DirectC 使用 Y；PreC/ProbeC 逐值复用旧臂的 Q=.5Y+.5 Teacher OOF 概率 |
| 权重 | 原 W=abs(F1(BM25)−F1(Dense))，abs(gap)≤1e−12 时权重为零；归一和未惩罚截距不变 |
| Teacher | 不重训、不重建目标；沿用 Student outer-fit 内严格组 OOF 生成且已独立核验的目标 |
| 推理 | 原 CUDA BF16 batch8 线性头；logit>0 选 BM25，否则 Dense；无 cal 校准或新阈值 |
| 规模 | 5 折×3 臂＝15 次正式拟合；另用已固定的旧 64 行小试目标做 3 次小试 |

Teacher 的概率不是 F1 gap；本轮始终使用原 W 加权的软 BCE，没有将概率或 logit 当成同单位的效用回归标签。cal 仅用于记录 BCE，不选参或调整决策。完整参数与摘要见[协议](../../outputs/router/hotpotqa_bd_router_v1/runs/m6_student_compensation_v1/protocol.json)。

## 3. 六项主比较与两个门槛

共享 20,000 次 group bootstrap，seed=2026091512，逐次按抽中 query 数归一。六项使用 [.05/12, 1−.05/12] 分位点，即双侧 **99又1/6%** 条件区间，对应六项名义 Bonferroni 家族。

| 主比较 | F1 差 | 条件区间 |

| ProbeC−DirectC | +0.000562358 | [−0.001669066, +0.002850489] |
| ProbeC−Direct | −0.000386656 | [−0.002008175, +0.001199281] |
| ProbeC−Dense | +0.004409720 | [−0.000447591, +0.009417657] |

配方推进门要求第 2–4 项都满足点值≥.002 且下界>0，实际为 **false**。候选准备门还要求第 5–6 项都满足点值≥.01 且下界>0，实际也为 **false**。交互的点值为正，但区间跨零；它既没有确认补偿对 Probe 的帮助超过对 Direct 的帮助，也不能代替净收益门。

区间只条件于当前固定 OOF 预测与 group 抽样，不包括重训练、Teacher 估计、历史开发选择或新来源的不确定性。旧总体效果和诊断已经用于提出本轮问题，评价独立性没有恢复。上界低于门槛的判断仅适用于相应比较和上述条件，不应统一写成“所有迁移比较均排除 .002”。

## 9. 对研究假设的更新与停止决定

本轮使解释更具体：此前的一般收缩确实可以按数学指定的补偿值缓解，PreC 参数及策略表现都回到更接近原 Direct 的位置；但 **ProbeC 仍没有确认比 PreC 更好，也没有达到相对原 Direct 的 .002 净增量**。因此，“只要补偿原正则就能释放足够 probe 迁移收益”没有得到本次固定对照的支持。

交互区间和 ProbeC−DirectC 区间仍保留部分正增量可能；停止依据是预先规定的整体推进门没有通过，而不是声称每个可能增量都已被统计排除。当前结果也不能唯一分开 Teacher 估计误差、M6 表示限制、线性函数类和固定零边界的影响。

**本次解析补偿配方结束，没有合格候选，不沿该分支追加搜索。** 若未来重开训练，须有不同且可区分的新证据与另行冻结的设计；现有八个策略不能因反复比较而取得独立确认资格。来源审查与独立评价准备可另行推进，但本轮没有模型可据此直接进入部署。
