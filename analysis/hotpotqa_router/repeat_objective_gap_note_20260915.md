## 2. 先平均与逐次加权：精确差异

以下先忽略 1e−12 容差。对一个 query，取有限个跨动作差值 d_k，令 g=mean(d_k)、c=mean(abs(d_k))、κ=c−abs(g)≥0，定义 h(s)=log(2cosh(s/2))。加权二值 BCE 满足

$$
|d|\,\ell(\mathbf{1}[d>0],s)=|d|h(s)-\frac{d}{2}s.
$$

因此先平均 gap 的损失 A 与逐次加权平均的损失 R 为

$$
A(s)=|g|h(s)-\frac{g}{2}s,\qquad
R(s)=ch(s)-\frac{g}{2}s,
$$

$$
R(s)-A(s)=\kappa h(s),\quad
R'(s)-A'(s)=\kappa(\sigma(s)-1/2),\quad
R''(s)-A''(s)=\kappa\sigma(s)(1-\sigma(s)).
$$

也可把 R 写成权重 c、软目标 Q=(c+g)/(2c) 的 BCE；c=0 时该行权重为零。**两种目标的有向 gap 项相同；逐次目标额外加入随 query 变化的偶对称置信度惩罚。** g=0 但 c>0 的抵消型 tie 因而会参与训练，拉向零分数。不能把这简单称为更多独立标签或无偏降噪。

原 W 在 fit 内归一。令 S_A=sum(abs(g_i))、S_R=sum(c_i)。若两种损失都各自归一而保持相同 λ，则把 R 的完整目标乘以 S_R/S_A 后，除上述附加项，还等价于把原坐标正则增强为 λS_R/S_A。若未来要单独检验 κ 项，应只用相应 fit 计算比例，并预先固定 λ_R=λ_A S_A/S_R；这只是归一补偿，不是推断其一定有益。

## 3. 配对、容差与有限重复的限制

**相同 repeat 编号不代表两动作具有共同随机种子。** E08 已显式处理这一点。若只使用 (B_0−D_0,B_1−D_1,B_2−D_2)，g 不变，但 c 会依任意编号配对改变。全部九个 B_r−D_s 的均值仍精确等于 mean(B)−mean(D)，且 c 对两动作各自编号置换不变，更适合先做目标诊断。九个差值共享六个答案，不能当作九个独立 query 或九倍样本量。

容差必须按实际代码另行保留：令 t(d)=d×1[abs(d)>ε]。先平均目标的有向量为 t(g)，逐次目标的有向量为 mean(t(d))；二者不再严格相同，精确损失差为

$$
\bigl(\operatorname{mean}|t(d)|-|t(g)|\bigr)h(s)
-\frac{\operatorname{mean}t(d)-t(g)}{2}s.
$$

有向修正的绝对值至多 2ε；不能只保留 κ 恒等式却在实现中静默删去近零项，也不能为了使分解看起来非负而截断估计。

若重复条件独立、同分布且均值稳定，E(abs(mean_R(d)))≥abs(E(d))。这说明有限重复的绝对值权重存在 Jensen 差异，但不等于已估计出每条 query 的真实权重偏差。三次重复不能可靠确定任意 query 的噪声分布；全局随机归一还使“期望之比”等式不成立。全部 cross9 的 c 针对随机跨动作差值的绝对质量，更多重复也一般趋向 E|B−D|，而不是 |E(B−D)|。

## 4. 仍可执行、但暂不启动的检查

首先可在原已曝光 repeat 缓存上固定一个只读诊断：核对两种 loss/gradient 恒等式、全部编号置换不变性、各 fit 的 S_R/S_A、κ 在当前固定 M6 头上的附加梯度和抵消型 tie 贡献。不能重复 E08 的九旋转 oracle 来宣称新的可部署证据。

只有该诊断提出具体可区分的问题时，才考虑一个固定 M6 的 matched 目标对照，并用解析归一补偿隔离 κ 项；它检验的是代理目标敏感性，不能单独判定“噪声主导”或“表示无信息”。若问题是已有策略差异对测量时段是否敏感，可另定范围比较固定策略在已消费 1,000-query 新旧重测标签上的差值；保持策略和 query 不变，不据结果改阈值或选择胜者，也不能把旧重测恢复成新独立验证。

当前优先级转向另一覆盖缺口：对已训练 full-FT checkpoint 的中间层 mean6 做匹配读出。此处不新增重复目标模型，也不追加答案生成。
