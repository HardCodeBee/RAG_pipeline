# 固定 M6 表示：训练目标与动作阈值对照结果

2026-09-15。**实验和独立数值复核已完成；当前 Ridge 配方未通过继续推进门槛，未产生新候选。** 这是已消费旧9600上的开发实验，不能替代另一来源的独立确认。

## 1. 研究问题与设计

完整 BEIR 验证中，冻结 M6 相对 Dense 的收益很小，有益与有害切换大量抵消。本轮检验：在相同 M6 表示上，直接拟合答案效用差的 Ridge 是否优于原效用加权 BCE；共同校准动作阈值后，差异是否仍存在。

依据：[预定设计](m6_objective_readout_plan_20260915.md)、[BEIR 完整结论](m6_beir_validation_conclusion_20260915.md)、[两种目标的含义](m6_loss_semantics_20260915.md)。两种理想目标具有一致的最优动作边界，但有限线性训练配方不同。本轮同时改变损失、tie 的参与和内层选参指标，不能将差异单独归因于其中一项。

沿用原9600 query / 9559 group，以及五折 fit6144 / cal1536 / test1920；输入是同一冻结模型第6层普通 WordPiece 均值池化并经 L2 归一化的384D M6。监督为已有三重复平均 normalized-token answer F1 的 BM25−Dense 差。本轮没有增加 encoder 前向、答案生成或 BEIR 新政策评价。

| 政策 | 训练 | 动作规则 |
|---|---|---|
| L0 | 复用原效用加权 BCE 线性头 | 原生 BF16 分数 > 0 |
| Lt | 同一原头 | cal 上最大化答案效用的阈值 |
| R0 | 同一特征上的直接 gap Ridge | 原生 BF16 分数 > 0 |
| Rt | 同一 Ridge 头 | 与 Lt 相同的 cal 选择规则 |

Ridge 使用不惩罚截距的平均平方损失，固定五个 lambda，以原 own-fit 三组验证的原生 BF16 MSE 选参。共80次正式求解、10个阈值选择。所有五个新头与十个阈值先固定，再产生全部新外层预测，最后计算效果。

## 2. 执行可信度

- [协议](m6_objective_readout_v1/protocol.json)绑定4个源码/设计文件、16个原输入和依赖版本；SHA256 为 `5353925ebd08af354ac7e7452b2b2e16432bb5862692aba2b6b8f49dd2358ca4`。
- 正式前的小试重放480条原头分数，全部逐值一致；另一次128行 Ridge 求解梯度为1.39e−17。数学模块14项合成测试及独立 checker 的14项合成检查通过。
- 正式80次求解全部接受，记录的最大完整梯度为1.85e−16。独立执行记录核验确认80份参数、标量与逐折归档完全对应，源/输入/模型/预测绑定一致。
- [独立数值复核](m6_objective_readout_v1/separate_checks.json)重新计算80个解的原坐标目标与梯度、10个穷举阈值、策略贡献、五项效应及全部逐折量；用频数加权法独立重算20000次 group bootstrap。主区间最大误差1.74e−17，阈值目标误差0。
- 正式运行及检查均正常退出，无中止、重试、改协议或结果后的选参。正式运行34.36秒；新增API费用为0。

独立 checker 核验的是数值和已保存的原生分数运算，没有重新执行 GPU 推理；GPU 路径由前述原头重放和源代码检查另行核实。这里的“独立”指另一数值实现，不是独立样本或外部研究团队复现。

执行证据：[小试](m6_objective_readout_v1/pilot.json)、[全部拟合完成](m6_objective_readout_v1/fit_completion.json)、[全部预测固定](m6_objective_readout_v1/predictions_frozen.json)、[完整结果](m6_objective_readout_v1/results.json)。

## 3. 五项预定主要结果

区间为逐 query 加权的 group bootstrap 双侧99%条件区间；五项使用共同20000次抽样，种子2026091501。区间条件于本次OOF预测，不包含重拟合、选参、阈值重选或历史研究选择的不确定性。

| 主要比较 | 平均 F1 差 | 99%条件区间 |
|---|---:|---|
| R0−L0 | −0.001860 | [−0.004885,+0.001015] |
| Rt−Lt | −0.003024 | [−0.006459,+0.000390] |
| 校准交互：(Rt−R0)−(Lt−L0) | −0.001164 | [−0.005509,+0.003321] |
| Rt−Dense | +0.002472 | [−0.003153,+0.008121] |
| Rt−BM25 | +0.030507 | [+0.022886,+0.038400] |

**配方推进门与候选准备门均未通过。** 预定的配方推进要求 Rt−Lt 下界>0且点增量≥0.002；目前上界仅+0.000390。在当前条件推断范围内，不支持并排除了预定幅度的配方增量；区间仍跨零，不能称已证明 Ridge 更差。

Rt 相对最佳固定 Dense 的区间跨零，上界也低于+0.01。优于较弱的固定 BM25 不能替代完整门槛。不能事后把点值最高的 Lt 改称本轮成功候选。

## 7. 判断更新与下一步

1. **当前直接 gap Ridge 优于加权 BCE 的假设被削弱。** 原始和共同校准两格均没有明确改善；按预定规则结束这组配方比较，不将负结果用作追加lambda或阈值的理由。
2. **单靠当前 cal 规则能解决收益不足的解释没有得到支持。** 两类头的校准点增益很小或为负，交互区间跨零；不能唯一归因为动作位置、排序或校准噪声。
3. **固定表示的非线性读出仍未被本轮检验。** 既有 A/G 表示的树模型不是同一 M6 输入。下一项值得准备的问题是：固定 M6 与原答案效用加权目标，改变线性函数类，能否增加外层有益选择而不过量增加有害选择？须先限定模型、优化与比较预算并冻结新协议；这不是已取得的能力，也没有在本轮启动。
4. **证据来源仍是硬边界。** 旧池、fresh4000、12566及本次BEIR均已消费；旧数据再分折不会恢复研究独立性。即使下轮出现内部候选，也需要另一份预先冻结的独立验证，才能支持目标分布上的稳定收益。

核心研究目标仍未达到，主运行时尚未集成自适应 Router。本轮贡献是完成一个可复核的配方排除实验，并缩小接续问题。
