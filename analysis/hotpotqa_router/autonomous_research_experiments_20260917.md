# 自主独立研究：全部实验、证据与判断变化

整理日期：2026-09-17。本文回顾 `researcher.md` 所对应的自主研究阶段：E01–E19、随后未沿用 E 编号的研究分支，以及截至 9 月 17 日完成的 M6 后续实验。历史 Phase 0–2.11/31 仅在作为输入或对照时引用，不冒充本阶段新增实验。

本文由现存实验报告、协议、结果和当前登记状态整理；本次整理没有启动训练、生成或新科学实验。实验按用户要求保持暂停。章节按科学问题组织，部分分支在历史执行时间上交错；不能把本文章节顺序当作严格的执行时间顺序。

## 0. 先给出总体判断

**已经完成了大量真实训练、诊断和三次冻结候选的独立数据验证；尚未实现“检索前 Router 在独立数据上稳定、显著且有实际意义地优于最佳固定策略”。**

最主要的结果是：

1. 冻结表示的中间层均值池化 M6，在旧池内部优于末层 CLS 对照；但 5,209 条独立条件来源上的 M6−Dense 为 **+0.003704**，97.5% 区间 **[−0.001379,+0.008972]**，未达到原 +0.01 目标。
2. 真实检索后 probe 在匹配的 M6/BCE 读出下有明确内部增量：相对 M6 **+0.009581**；但两代严格 OOF Teacher→Student 实验均没有确认足够的检索前迁移收益。
3. 辅助监督可学、训练集可拟合、校准可改善、参数更新真实发生，这些前提多次得到验证；它们没有自动转化为更好的留出答案决策。
4. 词项池化、校准、扩充监督有局部正向发现，但独立验证或匹配增量门槛不足。不能把它们全部称为“无效”，也不能把它们组合成已经成功的方法。
5. 最大限制已从“有没有更多旧池实验可做”转为“什么新假设能产生可推广结论，以及用什么独立证据验证”。

当前状态依据：[研究登记](registry.yaml)、[研究贡献评估](research_contribution_review_20260917.md)、[进展总报告](research_progress_report_20260915.md)。研究原则依据：[researcher.md](../../researcher.md)。

## 1. 所有实验共同回答什么

### 1.1 目标和输入边界

对同一问题 q，BM25、Dense 各产生三次回答；以 normalized-token answer F1 的均值定义效用：

\[
U_a(q)=\frac{1}{3}\sum_{r=1}^3 F1_{a,r}(q),\qquad
\Delta(q)=U_B(q)-U_D(q).
\]

Router 在检索前选择 BM25 或 Dense。相对始终 Dense 的收益为：

\[
G=\frac1N\sum_q\mathbf1[\pi(q)=B]\Delta(q).
\]

因此，既要找到 BM25 有益的问题，也要避免有害切换。只增加 BM25 使用次数、提高胜负分类准确率或降低训练损失，都不能替代最终的 G。

| 信息 | 在线何时可用 | 本研究允许的角色 |
|---|---|---|
| 问题文字、冻结 query encoder、固定语料统计/原型 | 检索前 | Router 输入 |
| 两路分数、检索文档及上下文关系 | 检索后 | probe 诊断或离线 Teacher 输入 |
| supporting facts/qrels、参考答案、生成答案及其 F1 | 离线评价或训练时 | 监督和诊断，不进入 pre-only 推理 |

后文“Teacher 很好”不等于“Student 有效”；“检索后政策提升”也不等于检索前目标完成。

### 1.2 常用模型和统计口径

- 早期基线通常为旧 30D 结构特征加冻结 BGE 的 own-fit PCA32，共 62D，再做 Ridge。旧 30D 包含 17D 词面/语料统计与 13D 原型相关摘要。
- M6 是冻结 BGE 第 6 层普通有效 WordPiece 的均值池化、L2 归一化，384D；C12 是末层 CLS。M6 最终使用效用加权 logistic/BCE 线性头。
- 效用加权 BCE 的标签为 `1[Δ>0]`、权重为 `abs(Δ)`。其理想概率是正效用质量占总绝对效用质量的比例，不能直接解释为普通胜率，更不能当作 F1 gap。
- 常用五折为每折 fit 6,144 / cal 1,536 / test 1,920，按信息需求 group 隔离；部分早期实验采用三种外层 seed 与嵌套内折，须以各自协议为准。
- 全文 F1 使用 0–1 标度：**+0.01 是一个绝对 F1 百分点**。CI 表示置信区间；不同实验因主要比较数不同使用不同置信水平，不统一改成 95%。
- 内部 bootstrap 区间通常条件于固定 OOF 预测，不涵盖全部历史方法选择、重新训练和重叠训练集的不确定性。旧池的五折不是五次独立复现；重复回答也不是新增独立问题。

### 1.3 数据分别承担什么角色

| 数据 | 规模 | 本阶段用途与边界 |
|---|---:|---|
| 旧池 | 9,600 query / 9,559 groups | 绝大多数开发、训练、消融与诊断；反复消费 |
| 检索分层扩充池 | 7,885 query | 与旧组隔离，但按历史检索获取层组织；不能当自然随机扩充 |
| 首次独立验证 | 4,000 query / 3,958 groups | 冻结 E03b 候选；仅 823 个切换问题采完整两动作标签 |
| 词项池化独立验证 | 12,566 query / 12,317 groups | 冻结 I/N；2,526 个切换并集采完整标签；两个原分区合为一次验证 |
| M6 独立条件来源 | 5,209 query / 5,206 groups | 全部两动作各三次，31,254 个答案；完成后已消费 |

旧池 Dense 平均 F1 为 **0.648209**，BM25 为 **0.620175**，事后 oracle 约 **0.717565**。oracle 的约 +0.069356 空间说明两动作存在互补，不能证明仅从 query 就能辨认这种互补。

## 2. 第一组：监督是否对准答案效用，扩充数据与校准能否帮助

### 2.1 E01：答案监督与检索覆盖代理的对照

**问题。** 覆盖支持页面这样的检索目标更易学习，是否比直接答案差更适合作为路由监督？

**设计。** 固定旧 30D＋PCA32、Ridge α=10，比较答案 F1 gap、支持页面覆盖比例差、完整覆盖指示差；代理模型分别使用原生决策及答案 cal 校准。三种 outer seed、五外折、四内折。

**结果。** 答案监督相对 Dense 为 +0.002455；覆盖比例原生为 −0.000191，完整覆盖原生为 +0.000150；加答案校准后分别为 +0.002268、+0.001140。主要对照没有确认超过直接答案监督。代理差的误差改善约 7.77%/6.72%，高于答案差约 0.77%；使用真实覆盖信息的事后规则可达 +0.026574/+0.016507。

**判断。** 代理可预测、真实代理有价值，仍不足以让预测代理产生更好的答案动作。这推动了“改变表示而非只换回归目标”的 E02，也保留了校准来源问题。[报告](../../../work/router_research/e01_report.md)

### 2.2 E02、E02b：真实微调与统一读出

**E02 设计。** 五折各训练三臂：A 冻结 encoder 只训 F1 头；B 微调末两层和 F1 头；C 在 B 上加入两动作覆盖率辅助任务。query-only CLS、三 epoch，共 15 次真实训练。

**E02 结果。** A/B/C 相对 Dense 分别为 −0.000875/−0.000437/−0.000562；B−A 为 +0.000439，C−B 为 −0.000125，97.5% 区间都跨零。C 的覆盖差预测 skill 为约 6.14%，说明辅助任务并非完全没学到。

**E02b 设计与结果。** 固定上述 15 个 checkpoint，改用统一旧 30D＋各自 PCA32＋Ridge 读出。A/B/C 相对 Dense 为 +0.000541/−0.000324/+0.001685；C−B 为 **+0.002009**，97.5% CI **[−0.000107,+0.004097]**。普通 95% 区间为正，但不能替换预定的 97.5% 标准。

**判断。** 已真实做过辅助微调，也发现表示与结构特征可能互补；尚未确认覆盖辅助提升最终路由。三 epoch 的阴性不能当作充分训练后的能力上限。[E02](../../../work/router_research/e02_report.md)、[E02b](../../../work/router_research/e02b_report.md)

### 2.3 E03：补充样本的数量、胜者筛选和 ties

**设计。** 在固定旧池评价上，引入组隔离的 7,885 条历史检索分层扩充：3,240 个既选 winner、4,363 个 ties、282 个其他 winner。比较仅旧池、加筛选 winner、加同数量随机扩充、winner＋ties、全部扩充；共同保持旧来源校准。

**结果。** 五种相对 Dense 点增益依次为 +0.002455、+0.003791、+0.002516、+0.003511、+0.003695。五项主要差的 99% 区间均跨零。未经目标来源校准时，扩充模型的 BM25 使用率约 54%–59%；旧来源校准后约 17%–18%。

**判断。** 未确认增加样本或胜者筛选的增量；观察提示训练来源与动作位置值得分开研究。该扩充池的获取机制限制了外推。[报告](../../../work/router_research/e03_report.md)

### 2.4 E03b：校准应该用哪种来源

**设计。** 固定 E03 模型及共同的 inner-OOF 预测，比较只用旧来源 cal 与混合旧/新来源 cal，避免把重新训练和校准变化混在一起。

**结果。** winner 扩充模型采用旧来源校准，相对混合校准提高 **+0.005284**，97.5% CI **[+0.000487,+0.010128]**；两者相对 Dense 为 +0.004421/−0.000863。全扩充模型的对应差为 +0.004597，区间跨零。

**判断。** 特定固定模型下，匹配目标来源的校准有内部证据；不能推成普遍的来源校正定理。E1-old-cal 被选为第一次独立验证候选。[报告](../../../work/router_research/e03b_report.md)

### 2.5 E04：第一代严格 Teacher→Student 蒸馏

**设计。** 75 个 XGBoost Teacher 与 20 个 Ridge Student。Teacher 三臂分别使用 pre414D、pre414D＋50D 检索后 probe、pre414D＋34D gold；Student 只用旧 30D＋PCA32。Student 目标为半真实 gap、半 Teacher gap；每个 Teacher 目标在 Student 自己的 fit 内按组 OOF 生成，排除 cal/test。

**结果。** pre/probe/gold Teacher 相对 Dense 为 +0.000624/+0.012618/+0.039271。Direct/Pre/Probe/Gold Student 分别为 +0.001425/+0.001457/+0.001369/+0.001663。Probe−Pre 为 −0.000087，Gold−Pre 为 +0.000207，主要区间都跨零。

**判断。** 这是真实完成的蒸馏，不是只做 Teacher 诊断；但高质量特权 Teacher 没有带来可确认的线性 pre-only Student 增量。gold 头只能说明离线条件信息的价值。[报告](../../../work/router_research/e04_report.md)

### 2.7 第一次独立验证：fresh4000

**设计。** 在新 4,000 条、3,958 groups 上，先冻结 E03b E1-old-cal 的动作；对 823 个 BM25 切换 query 采集两动作各三次，共 4,938 个答案。其余 query 相对 Dense 的政策差按定义为零，足以估计这一固定候选的配对增益。

**结果。** 候选−Dense 为 **+0.002428**，95% CI **[−0.002281,+0.007069]**；EM 增量也未确认。点值不足 +0.01。

**判断。** 内部候选没有获得独立确认。未切换 query 的真实 BM25−Dense 差仍未知，不能补成 tie，也不能从局部采集推得全体绝对 F1 或 oracle。[完整报告](../../../work/router_research/fresh4000_final_report.md)

## 3. 第二组：是否训练不足，噪声、辅助任务或校准能解释失败

### 3.1 E08：三重复标签中的随机成分

**设计。** 复用旧 57,600 个答案，分解 mean3 gap 方差，并用跨重复选择/评价避免在同一次回答上选动作和评价。没有重训或新生成。

**结果。** 在条件独立和均值稳定假设下，噪声占 mean3 gap 方差约 **3.553%**，95% CI [3.232%,3.905%]；三重复事后 oracle 增益约 +0.069356，跨重复选择评价约 +0.064761。153/9,600 个 query 出现重复间正负翻转。

**判断。** 大部分观察差异不宜直接归为单次生成噪声；但稳定差异不等于 query 可预测，小 gap 决策仍可能受噪声影响。oracle 差额还包含用更少重复选动作的错误，不能全称为评价偏差。[报告](../../../work/router_research/e08_report.md)

### 3.2 E09 及冻结 probe 基线：辅助信号是否只学到共同难度

**设计。** 增加五个末两层模型 D，在答案差任务之外学习八个不使用 qrels 的检索后目标：两动作 margin、entropy、query/context Jaccard，以及 top1 一致性、top5 文档集合重叠。统一用旧 30D＋PCA32＋Ridge 评价。

**结果。** D−Dense 为 +0.000426；D−B 为 +0.000750，D−C 为 −0.001259，97.5% 区间均跨零。部分辅助预测确有改善，例如 Jaccard 共同量 skill 51.81%、差值 skill 8.59%。

**配套诊断。** 冻结原 query 表示的简单 Ridge，已能预测 Jaccard 共同量 33.75%，动作差仅 5.44%；entropy 差 skill 为负。说明“两个动作的指标都能预测”与“二者差异可预测”不同。

**判断。** 多机制辅助任务确实训练过，但未确认答案收益；不能只引用辅助指标改善。[E09](../../../work/router_research/e09_report.md)、[冻结基线](../../../work/router_research/e09_probe_baseline_report.md)

### 3.3 已完成 encoder 的拟合诊断

**设计。** 读取 E02 A/B/C 与 E09 D 的固定 checkpoint 和缓存，检查最终头的 fit/cal/test gap 平方误差，不重训。

**结果。** A/B/C/D 训练 skill 约 1.55%/4.46%/3.16%/3.78%，test 约 0.22%/0.09%/0.42%/0.54%。训练也远未精确拟合。fit 为缓存上的近似重放，不能声称逐值复现了未保存的 fit 原预测。

**判断。** 不能提前认定 encoder 已充分拟合、剩下只是校准；需要进一步区分优化能力与泛化。[报告](../../../work/router_research/cached_fit_diagnostic_report.md)

### 3.4 E10 与排序/数量分解

**设计。** 五个末两层 encoder 改为效用加权 BCE，仍三 epoch，与 E02 B 匹配。ties 保留在批次中但监督权重为零。

**结果。** 原生策略−Dense 为 +0.000814；相对 E02 B 原生策略为 +0.002651，97.5% 区间跨零。BM25 比例从 27.72% 降至 3.32%，AUC 约 0.548→0.547。

**诊断。** 固定每折原两种切换数量，交叉替换排序，+0.002651 描述性分解为排序 +0.000876、数量 +0.001775。约 67% 来自这个特定代数分解的数量分量；不是损失函数因果效应的比例。

**判断。** 决策损失改变了策略，但不能把少切换自动解释为学会了更好的辨别。[正式报告](../../../work/router_research/e10_report.md)、[四格诊断](../../../work/router_research/e10_coverage_diagnostic_report.md)

### 3.5 E11A、E11C：能否拟合，以及拟合后是否泛化

**E11A 小样本正对照。** 固定 128 个独立 group 的非 tie query，真实标签与完整置乱标签各训 2,048 步；两者 BCE 都约 0.0061、错误率均为零。冻结 CLS 增广矩阵秩为 128，线性头本身就能插值两套标签。因此结果证明该小样本可拟合，不证明有语义学习或完整池泛化。

**E11C 正式设计。** 完整 fit 训练到加权 BCE≤先验的 10% 且加权错误率≤1%，最多 32 epoch。五折在 12/13/14/13/13 epoch 达标。

**结果。** 训练错误率约 0.62%–0.97%，test 约 42.68%–44.87%；test BCE 1.7595，高于先验 0.6831。相对 Dense **−0.003706**，97.5% CI [−0.009090,+0.001622]；比 E10 点值更低。

**判断。** 训练能力与泛化必须分开：延长训练实现了高精度拟合，没有改善路由。E11A 和 E11C 是有实际结果的子实验；本文不补造一个 E11B 正式结果。[E11A](../../../work/router_research/e11a_report.md)、[E11C](../../../work/router_research/e11c_report.md)

| E12 | 固定 E11C 终点，仅在 cal 做非负仿射 BCE 校准 | BM25 比例 43%→7.292%；相对 Dense −0.000773，较原生 +0.002933；主要区间跨零，四折变成全 Dense | 校准可减少过度切换、改善连续损失，但未确认答案收益。[报告](../../../work/router_research/e12_report.md) |

### 3.7 共同答案质量诊断与 E14

**前置问题。** `C=(U_B+U_D)/2` 是否比差值更有可学信号，可作为共享 encoder 的辅助监督？

**两个固定表示诊断。** 旧 30D＋PCA32 预测 C，skill **9.8937%**；只用 query PCA32 仍有 **1.6143%**，MSE 改善的 97.5% 区间为正。原 gap skill 仅 0.5525%、区间跨零。不能用两个目标绝对 MSE 直接比较学习难度。

**E14 设计。** 在加权 BCE 主任务之外加入 C 的 MSE 辅助任务；沿用 E13 的训练范围和 cal 效用选择，五个模型、49,920 步。C 对 ties 也提供监督。

**结果。** E14−Dense 为 **−0.001433**，E14−E13U 为 −0.000358，97.5% 区间均跨零；最终 C 头 fit skill 约 76%–83%，test skill 为 −11.84%。

**判断。** 共同难度确有可读信号，却未通过这套联合训练改善动作差；不能因前置预测为正就宣称辅助迁移成功。预设门未过，没有继续开置乱 C 对照。[共同量](../../../work/router_research/common_answer_predictability_report.md)、[query-only 诊断](../../../work/router_research/common_query_only_report.md)、[E14](../../../work/router_research/e14_report.md)

## 4. 第三组：表示遗漏、词项池化与第二次独立验证

### 4.1 E15：相似问题是否具有相似策略优势

固定归一化 384D CLS，使用 fit 中 64 个余弦近邻的平均连续 gap，与匹配 Ridge 比较；不搜索 K、不使用 cal。KNN−Dense **−0.006292**，97.5% CI **[−0.010936,−0.001598]**。KNN gap skill −0.9649%，共同答案量 skill 却为 +2.7996%。

**判断。** 这套语义近邻局部平滑并未产生有利路由；语义相似与检索策略优势相似不是同一件事。[报告](../../../work/router_research/e15_report.md)

### 4.2 E16：加入 query 的 contextual 词项池化

**设计。** 在旧 62D 上增加 32D 池化 PCA；比较均匀池化 U、真实 IDF 池化 I、三个 query 内置乱 IDF 对照。encoder 冻结，25 个 Ridge。

**结果。** N/U/I 相对 Dense 为 +0.000541/+0.002127/**+0.002875**；三个置乱对照约 +0.002012/+0.002215/+0.002444。I−N 为 **+0.002334**，98又1/3% CI **[+0.000862,+0.003889]**；I−U 为 +0.000748，区间跨零。

**判断。** 支持固定词项池化增加有用输入；没有单独确认“正确 IDF 权重”是改善机制。不能将所有池化增益归于 IDF。[报告](../../../work/router_research/e16_report.md)

### 4.3 E17：新信息还是重复特征改变正则

**设计。** 用 fit 内无标签线性投影，将新增池化特征 Z 分解为旧输入 X 可预测部分 S 和残差 R，分别拼接比较。

**结果。** I−[X,S] 为 +0.002134，R−N 为 +0.002054，98又1/3% 区间为正；R−Dense 为 +0.002595，区间 [−0.000006,+0.005219]。X 可解释约 82% 的 fit 特征能量，不是“82% 决策信息”。

**判断。** 池化增量不能完全用重复线性信息改变惩罚解释，但对 Dense 的直接证据仍有限。v1 在策略评价前因正交性数值检查失败；v2 加两步残差精化，原失败记录保留，不改变特征/容差/研究标准。[报告](../../../work/router_research/e17_report.md)

### 4.4 E18、E19：划分稳定性与轮换校准

**E18。** 固定第二个 group split，N/I 共 10 个 Ridge。I−Dense **+0.004072**，97.5% CI [+.000378,+.007808]；I−N +0.000922，区间跨零。N 自身也由旧 +0.000541 升至 +0.003150，显示划分变动不可忽略；换 seed 不等于新样本验证。

**E19。** 固定 E18 外折，让训练区轮换五个 fit/cal 角色，对校准分数取平均。I 平均−Dense **+0.004768**，98又1/3% CI [.001317,.008186]；I 平均−N 平均 **+0.002275**，[.000589,.003977]；I 平均−I 单模型 +0.000696，区间跨零。

**判断。** 存在值得验证的池化候选，但尚未确认平均本身优于单模型。随后选择 I 平均候选应披露开发选择，不把 E19 写成全部门槛通过。[E18](../../../work/router_research/e18_report.md)、[E19](../../../work/router_research/e19_report.md)

### 4.5 候选实际冻结与第二次独立验证

**候选准备。** 全旧池按五组轮换 fit/cal 拟合 N/I 共 10 个 Ridge，编译为 414D/798D 仿射读出；128 个原始 query 重放通过。旧 FP32 特征和 BF16 contextual pooling 不能随意合并，实际保留两种精度通路；当时并非一次 encoder 前向的线上实现。[准备报告](../../../work/router_research/pool_candidate_report.md)

**独立设计。** 新 12,566 query、12,317 groups，包含两个原分区但属于一次冻结验证；先冻结 N/I 动作，对切换并集 2,526 条采两动作各三次，共 15,156 个答案。

**结果。** I−Dense **−0.001538**，97.5% CI **[−0.004320,+0.001257]**；I−N **+0.001208**，CI **[−0.000333,+0.002726]**。均未确认。

**事后分解。** 两者都选 BM25 的 1,949 条对总体贡献 −0.001736；I-only 316 条贡献 +0.000198；N-only 261 条贡献 −0.001010。因此 I 相对 N 的点值优势很大程度来自避开 N 的坏切换，仍没有超过 Dense。按分数分层的事后阈值观察没有产生合格新策略。

**判断。** 词项池化的内部增量未变为独立效用提升；该验证已消费，不能继续用于据此修订的候选验收。[完整结果](../../../work/router_research/pool_independent_results.md)

## 5. 第四组：标签和测量链本身可靠吗

这组研究由独立验证不理想引出：先排查数据、回答生成和语义评分，避免在测量不清楚时继续解释模型。

### 5.1 历史输入、上下文与评分重放

复核旧 57,600 个答案的身份、字段和计分，重建 19,200 条上下文，并对 64 个 query 两动作重检索。文档 ID、顺序、上下文一致；BM25/Dense 分数最大差约 2.84e−14/1.79e−7。

**判断。** 未观察到能解释失败的上下文错配或评分实现错误；这不保证不同时刻的生成器输出完全稳定。[测量审计](../../../work/router_research/historical_measurement_report.md)

### 5.2 1,000 条生成重放

**设计。** 对旧池 hash 抽取 1,000 个 group，保持 query、上下文、prompt、固定模型版本、温度 0 和 max output 64，重采 6,000 个答案。

**结果。** 新旧 mean3 gap 的均值变化为 −0.002245，97.5% 区间跨零；扣除重复内估计噪声后的平方差统计为 **+0.005207**，CI **[+0.000689,+0.011106]**。大量赢家保持原方向，仍有部分问题发生变化。

**判断。** 没有确认总体方向偏移，但存在重复内噪声之外的变化证据，依赖条件独立/稳定性假设。不能仅凭此诊断为服务方模型漂移，也不能据此宣布全部历史标签失效。[结果](../../../work/router_research/generation_replay_results.md)

### 5.3 语义重评：F1 变化是否主要来自表达形式

**设计。** 同 1,000 条的新旧 12,000 个回答去重为 1,711 个 query-answer 对，用固定 judge 做 0/0.5/1 评分；对 judge 隐藏动作、采集时间、F1 和上下文。先做 24 条操作性校准，另抽 50 条重复评分。

**结果。** 24 条校准通过 22 条；50 条重评 49 条一致，κ≈0.9798，但不是人工真值。语义 mean-gap 变化 −0.001167，噪声调整后平方变化 +0.004278；98又1/3% 区间都跨零。F1 与语义调整统计之差 +0.000929，也跨零；严格赢家翻转 F1 为 8 条、语义为 1 条。

**判断。** 表达和评分粒度可能影响部分标签；现有结果没有确认“F1 格式噪声是主要失败原因”，也未完成可靠替代指标建设。[结果](../../../work/router_research/semantic_replay_results.md)

### 5.4 身份/yes-no 措辞探针

固定一个人物身份问题，做两种问法×四种答案形式×三次重复，共 24 次评分。原人名陈述形式不稳定，显式身份或 Yes 前缀形式更稳定；同一原始输入也出现过不同标签。

**判断。** 找到了一个真实的 judge 边界案例；不能由单例估计总体误判率，也没有据此覆盖原始评分。[结果](../../../work/router_research/semantic_identity_probe_results.md)

### 5.5 共享支持证据的 judge 校准与 scope 探针

**设计。** 八个案例、各两正两负答案、有/无共同 gold 支持证据、各三次评分，共 192 次；另加 24 次范围措辞探针。

**结果。** 正确答案通过数：无证据 46/48、有证据 45/48；错误答案正确拒绝数：42/48、47/48。证据改善了一部分身份判别和拒错，但两种设置都未同时满足全部预定标准。

**判断。** 未将 judge 扩为大规模新监督源。案例预期标签由研究执行者构造，不能称为独立人工金标准。[结果](../../../work/router_research/shared_evidence_calibration_results.md)

### 5.6 历史 F1 与 Answer Correctness 权重比较

在已有 600 query、3,600 个配对答案中，按 mean3 F1 gap 的绝对权重统计：**84.97%** 与 AC 动作差同向，**14.80%** 落在 AC tie，**0.23%** 严格反向。该 AC 也是已有固定 judge 评分，不是无误真值。

**判断。** 削弱“F1 普遍把策略优劣标反”的解释；保留约 15% 权重落在较粗语义评分打平处的局部错位问题。没有做删去这些样本后的训练验证，不能宣称这样删会改善泛化。[报告](../../../work/router_research/historical_metric_weight_report.md)

## 6. 第五组：用文档关系和支持事实训练 query 表示

### 6.1 文档偏好 encoder：能否学会偏好某路检索结果

**设计。** 五折分别训练 LB/LD，使 query 表示偏向 BM25/Dense 独有文档；固定文档向量，微调末两层，六 epoch，共 10 个 encoder、46,080 步。encoder 不直接用答案 F1，最终统一旧 30D＋PCA32＋Ridge 读出。

**结果。** LB−Dense +0.001379；LB−冻结 A +0.000838；LB−LD −0.000419，主要区间均跨零。随后 15 个 CPU 尺度对照中，scaled-B−A **+0.002282**，区间 [.000407,.004210]；但 scaled-B−Dense +0.002824 区间仍跨零，相对未缩放 LB 的增量也未确认。

**判断。** 没有通过完整路由门槛；局部尺度对照正向不能改写成文档偏好训练成功。[结果](../../../work/router_research/document_preference_results.md)

### 6.2 文档几何诊断：是否存在不需要问题内容的捷径

将原 query 向量反号，BM25 偏好率可从约 0.0165% 变为 99.9835%，而统一线性路由读出可保持等效。一个训练后模型在 cal 的真实 query/置乱 query/常量 query 偏好率约 84.90%/85.16%/85.11%。128,817 个文档对中大部分两边都未被标为支持证据，检索器来源并不等同相关性。

**判断。** 这套“偏好某路文档”的训练目标存在显著的全局几何捷径，未证明学习了问题特异的动作优势；需要更直接的支持关系监督。[结果](../../../work/router_research/document_geometry_results.md)

### 6.3 支持事实几何前提

固定文档关系，比较真实 query、置乱 query、优化常量向量及 gold 文档向量。支持匹配 cal 正确率分别约 90.64%、57.16%、68.43%、99.87%。最后一项为非部署正对照。

**判断。** 与检索器身份偏好不同，支持关系具有真实的 query 特异性，足以支持下一项监督实验；这不是 Router 效果。[结果](../../../work/router_research/support_geometry_results.md)

### 6.4 G：支持事实监督 encoder

**设计。** 在两路 top5 并集内，让已知 supporting document 排在未标注文档前；末两层训练五折×六 epoch，共 23,040 步。9,207 条有训练关系，393 条没有关系但仍保留在完整路由读出和评价。

**结果。** G−冻结 A **+0.001860**，97.5% CI **[+.000100,+.003664]**；G−Dense **+0.002402**，CI **[−.000288,+.005082]**。相对 A 有内部增量，未确认超过较强固定 Dense。

**迁移诊断。** 固定模型的 test 支持匹配正确率从 90.115% 升至 91.141%，差 +0.010262 的 97.5% 区间为正，匹配损失也下降。这证明辅助关系学到了部分可泛化信号；文档索引没有重新编码，不等于 Dense 实际召回改善。

**判断。** 这是较明确的“辅助任务改善但路由目标尚未过门”的实例。[训练结果](../../../work/router_research/support_encoder_results.md)、[迁移诊断](../../../work/router_research/support_transfer_results.md)

### 6.5 支持表示的完整 384D 读出

比较 A/G×PCA32/完整384D，保留同一旧 30D，共 20 个 Ridge。G384−Dense −0.000156；G384−G32 −0.002558；G384−A384 −0.000224，98又1/3% 区间都跨零。

**判断。** 没有证据表明只需取消 PCA 压缩即可释放支持监督收益；不能将这一次正则/维度对照当作表示的信息上限。[结果](../../../work/router_research/support_full_readout_results.md)

## 7. 第六组：标签数量、获取策略、读出与结构特征

### 7.1 标签数量曲线

**设计。** A/G 各取 fit 标签 25%/50%/100%，约 1,536/3,072/6,144 条；小规模各用三个嵌套 group 抽样，cal 固定 1,536，正则按样本数调整以匹配平均损失惩罚，共 70 个 Ridge。

**结果。** G 相对 Dense 点值约 +0.001036→+0.001560→+0.002402；full−25% 为 +0.001365，97.5% CI [−.000882,+.003622]。A 的曲线非单调，full−25% 为负且区间跨零。

**判断。** 不能确认“只要更多答案标签就会达到目标”。G encoder 已用完整 fit 的支持监督，因此曲线只改变最终答案标签数量，不是完整监督成本曲线。[结果](../../../work/router_research/answer_label_count_results.md)

### 7.2 分数的事后阈值包络

对 14 组固定分数做全局/逐折阈值扫描，共 84 个诊断包络，使用 test 标签，因此只作事后参考。G100 实际增益 +0.002402；当前分数的全局最优阈值 +0.004074，逐折最优 +0.006298，均低于 +0.01。

**判断。** 对这些已固定分数，单纯改阈值的经验空间有限；不能称为所有模型/所有分布上的理论上界，更不能部署用 test 选出的阈值。[结果](../../../work/router_research/score_threshold_envelope_results.md)

### 7.3 真正可执行的 cal 效用阈值

固定 A/G 分数，只在 cal 选阈值，包含全 Dense/BM25 常量规则，10 次阈值选择。G-U−Dense +0.001442，G-U−原 MSE 校准 −0.000960，97.5% 区间跨零。

**判断。** 直接按答案效用选阈值也已经实际试过；没确认改进。A-U 的较好描述点值不能事后替换预定主对象。[结果](../../../work/router_research/direct_utility_threshold_results.md)

### 7.4 答案标签获取：随机、覆盖差异、双向均衡

**设计。** 每折相同 768 个答案标签预算，每 group 一条：R 随机；D 只取两动作支持覆盖不同者；B 在两个覆盖优势方向各取 384。A/G、三次固定抽样，共 90 个 Ridge；cal 标签固定，G 支持监督不削减。

**结果。** G-D−G-R 约 +0.000028，G-B−G-D 约 −0.000059，97.5% 区间均跨零。

**判断。** 改变了标签组成，但没有确认效用收益；不能只用更高的非 tie 比例评价采样策略。[结果](../../../work/router_research/answer_acquisition_results.md)

### 7.5 获取策略的 30 次固定重复

**设计。** G 上预先固定另外 30 次采样，450 个 Ridge，不与前三次挑选合并。

**结果。** D−R 平均 +0.000066，获取随机性的 Monte Carlo 区间跨零；B−D +0.000385，Monte Carlo 97.5% CI [.000094,.000676]，30 次中 23 次为正。但按评价 query group 的区间 [−.000346,+.001109] 跨零。

**判断。** 说明这一固定池上的获取期望有局部正向差异，不能把降低采样 Monte Carlo 误差当成解决新 query 泛化。[结果](../../../work/router_research/acquisition_repeats_results.md)

## 8. 第七组：学习 query 之间的效用关系，或直接学习动作

### 8.1 Query-rank 表示训练

**设计。** 五折 M 为 gap MSE，R 为 MSE＋0.1 倍依据连续 gap 距离构造的关系损失，借鉴 Rank-N-Contrast 类思路；单位 CLS，最终共同 Ridge 读出，共 10 个 encoder。

**结果。** R−Dense −0.000267；R−M +0.000622，97.5% 区间跨零。test 关系损失 3.0907→3.0058，表示方差也由 0.8148→0.5768。

**判断。** 不能仅因关系损失下降认定学到有用效用结构，收缩/集中也会改变该损失。[结果](../../../work/router_research/query_rank_results.md)

### 8.2 关系损失的几何与对应关系诊断

固定表示，保留 group 块做标签置乱。真实对应相对置乱的 test 优势，M 为 −0.001156，R 为 +0.002692，差 +0.003849；大部分原损失差在置乱后仍然存在。

**判断。** 有部分真实对应改善，但原损失的大幅下降不能全归于这种对应；没有新增政策或显著性主张。[结果](../../../work/router_research/query_rank_geometry_results.md)

### 8.3 初始表示 A0 对照

补齐同精度原始 BGE A0，并拟合五个统一 Ridge。R−A0 −0.000809，M−A0 −0.001430，97.5% 区间跨零。test 距离排序正确率约 A0 .4927、M .4986、R .5073；R 对真实对应的优势主要来自零 gap 锚点，而非两个胜者方向。

**判断。** R 比 M 的局部关系改善，不足以证明超过未训练初始表示，且可能集中于动作无差异样本。[结果](../../../work/router_research/query_rank_initial_results.md)

### 8.4 关系损失分配：非零锚点与零锚点

十个新 encoder 比较只给非零 gap 锚点关系损失 NZ、只给零 gap 锚点 Z；保留所有伙伴和 MSE，以 fit 比例匹配预期权重。NZ−Dense −0.000082；NZ−原 All +0.000185；NZ−Z −0.000028，97.5% 区间跨零。

**判断。** 这项针对性分配没有解决收益问题，结束该固定关系训练分支；匹配预期权重不等于匹配随机梯度方差。[结果](../../../work/router_research/query_rank_allocation_results.md)

### 8.5 有限政策树：直接最大化动作收益

固定同一轴对齐树函数类和输入，比较直接最大化叶子正 gap 总和 W，与按 gap 平方拟合的 S，共十次拟合。

**结果。** W 训练增益约 +0.006098，S +0.002549；但 W−Dense 为 −0.002489，W−S +0.000364，97.5% 区间跨零，约 21% 动作改变。

**判断。** 更贴近决策的有限样本目标可改善训练决策，仍未确认泛化；不能据此说平方损失在总体上具有错误的最优边界。[结果](../../../work/router_research/policy_tree_results.md)

## 9. 第八组：全模型训练、LP→FT 与 M6 的发现

### 9.1 全 encoder 微调范围

**小试。** 68 步确认 embeddings、12 个 block 和头实际更新，约 3,321 万可训练参数，保存/恢复一致；工程可行性先于效果判断。[小试](../../../work/router_research/encoder_scope_pilot_results.md)

### 9.2 先训线性头、再全模型微调：LP→FT

**问题。** 从随机头直接微调可能破坏原表示；先得到好的线性头是否有帮助？

**执行链。** 小试验证头继承；v1 在第四个 LP 求解因梯度略高于原 1e−8 门槛停止，未产生正式质量结论。单独五个 λ 数值小试验证一次有界 Newton 精化，保持目标和接受标准，随后用新协议执行 v2。

**正式规模。** 80 个线性求解，形成五个 P；以其初始化五个全微调 H，与先前随机头全微调 F 对照。

**结果。** P−Dense −0.001978；H−Dense −0.001909；H−F +0.000581；H−P +0.000069，98.75% 区间均跨零。H 在 7/5/5/4/5 epoch 拟合达标，更快但未更好泛化。

**判断。** LP→FT 是实际测试过的已有方法组合，没有支持当前配方。数值中止不是科学阴性，v2 结果才是正式效果证据。[初始小试](../../../work/router_research/lp_ft_pilot_results.md)、[v1 中止](../../../work/router_research/lp_ft_first_rejection.md)、[精化小试](../../../work/router_research/lp_refinement_pilot_results.md)、[正式结果](../../../work/router_research/lp_ft_v2_results.md)

### 9.3 层位置×池化：M6 出现

**判断。** 在旧池上，读取层和池化方式比前述简单增大训练能力更有希望；发现的是现成表示中的可读差异，不能称为新 encoder 架构。M6 成为下一次冻结验证候选，仍需独立数据确认。[小试](../../../work/router_research/layer_pooling_pilot_results.md)、[正式结果](../../../work/router_research/layer_pooling_results.md)

### 10.1 固定 M6 在 7,885 条扩充来源上的迁移

不重训，评价已冻结候选。M6−Dense **+0.049181**，CI [.042007,.056311]；M6−C12 +0.031134，CI [.024518,.037821]；但 **M6−BM25 −0.006919**，CI [−.018365,+.004395]。三项均为 98又1/3% 条件区间。

### 10.2 收益来源分解

### 10.3 扩充训练与来源独立截距

**判断。** 全部扩充标签直接合并没有确认收益，联合学习来源截距也未通过门槛；不能进一步断言所有扩充方法无效，或严格确认负迁移。[小试](../../../work/router_research/m6_source_intercept_pilot_results.md)、[正式结果](../../../work/router_research/m6_source_intercept_results.md)

### 10.4 固定 P 系数，只在旧 cal 加一个偏移

**设计。** 固定 O/P 系数与原偏置，各自在原 cal 上拟合一个 logit 常数 c；O_C 为匹配校准控制，P_C 为扩充头校准。128 条两次小试后，正式十次标量拟合。

## 12. 第十一组：独立验证后，对 M6 的目标、非线性和特权迁移研究

以下全部回到已消费的旧池，没有新增独立来源确认。主问题是如何减少有害切换而保留有益切换。

### 12.1 同表示上的目标×阈值对照

**设计。** 固定 M6，比较加权 BCE 与直接 gap Ridge，并给两者相同的 cal 效用阈值选择；80 个正式求解、十个阈值。

**结果。** 原生 Ridge−BCE −0.001860，99% CI [−.004885,+.001015]；校准后 Ridge−BCE **−0.003024**，CI **[−.006459,+.000390]**；校准 Ridge−Dense +0.002472，CI [−.003153,+.008121]。

**判断。** 未通过配方门，校准后增量上界也低于 .002；结束这套 Ridge 替换。两种理想目标具有相同最优动作边界，本实验比较的是有限函数类、损失、ties 参与和内层选参共同构成的配方。[报告](m6_objective_readout_results_20260915.md)、[目标语义](m6_loss_semantics_20260915.md)

### 12.2 固定 Fourier 非线性扩展

**设计。** 在 M6 的 384D 线性项外加 384D sin/cos 随机 Fourier 特征，三个 fit 距离尺度、两个预定种子平均，160 次求解；仍用加权 BCE，不更新 encoder。

**结果。** 非线性平均−原 M6 **−0.000896**，98又1/3% CI **[−.003420,+.001642]**；相对 Dense +0.003900，CI [−.000681,+.008524]。fit BCE 下降约 .031，但增加的有害质量抵消了收益。

**判断。** 这套固定非线性配方未提供 .002 增量，停止追加种子/尺度；不能将一个成员的较好点值替换原定平均政策。它使用现有随机特征思想，不是提出新核方法。[报告](m6_fourier_readout_results_20260915.md)

### 12.3 匹配 M6 的真实 probe 与置乱对照

**问题。** 是当前表示/读出普遍不能利用信息，还是 query-only 输入确实遗漏了有用的检索状态？

**设计。** P 用 M6＋50D 不依赖 qrels 的真实检索后 probe；S0/S1 用两种固定按组置乱 probe，匹配维数、处理和选参。三臂 240 次求解，15 个最终头；原 M6 复用。

| 主比较 | F1 增量 | 99% 条件区间 |
|---|---:|---|
| P−M6 | **+0.009581** | **[+.004892,+.014284]** |
| P−S0 | +0.012175 | [+.007297,+.017053] |
| P−S1 | +0.010121 | [+.005251,+.014952] |
| P−Dense | +0.014378 | [+.008928,+.019862] |

**判断。** 在匹配配方中，真实对应的检索后特征有额外决策价值，不能只用新增维度解释。这通过了“值得研究迁移”的门，**没有通过 pre-only 候选门**；P 需要先运行两路检索。[报告](m6_probe_readout_results_20260915.md)

### 12.4 第二代严格 OOF Student

**设计。** Student 全部只输入 M6。Direct 用真实硬标签；Pre 用 .5 真实标签＋.5 pre Teacher 概率；Probe 用 .5 真实标签＋.5 probe Teacher 概率。保留原效用权重，Teacher/Student λ=.001。每个 Student own-fit 内三折 group OOF 产生 Teacher 目标，不能复用可能包含当前组标签的全局 OOF；共 30 个 Teacher、15 个 Student。

**结果。** Pre−Direct −0.000314；**Probe−Pre −0.000514**，99% CI **[−.001734,+.000697]**；**Probe−Direct −0.000828**，CI **[−.002730,+.001083]**。Probe−Dense +0.003969，CI 上界 .008298。迁移门和候选门均失败。

**判断。** Teacher 在自身 OOF 的 BCE 确实更好，但新增 probe 未转化为所需 pre-only 收益；完成了实际迁移检验，不是停留在建议。结束固定 α=.5/λ=.001 配方，不继续搜温度、α 或阈值。[报告](m6_student_transfer_results_20260915.md)、[预先目标推导](m6_distillation_rationale_20260915.md)

### 12.5 失败定位：监督是否真正进入 Student

**设计。** 固定上述所有产物，分解目标对线性 Student 的加权特征矩、参数响应、一般软化收缩及动作贡献，不新增拟合。

**结果。** Probe−Pre 的目标矩及中心化矩每折非零，系数变化范数约 .574–.681；改变 199 个测试动作，其中 24 个有益、29 个有害、146 个零效用。一般软化收缩可解释部分 Pre−Direct 参数变化，但公共收缩项在 Probe−Pre 中抵消。

**判断。** 阴性不是“没有实施蒸馏”或“probe 根本没进入模型”；一般收缩也不能单独解释 probe 特有增量失败。这是一项固定模型机制诊断，没有证明所有迁移不可能。[报告](m6_student_localization_results_20260915.md)

### 12.6 解析正则补偿

**设计。** 按自蒸馏收缩推导，把 Student λ 改成 `(1−α)λ=.0005`，同时训练匹配 DirectC/PreC/ProbeC，15 个新头，Teacher 和软目标不变；只做这个指定补偿，不扫描网格。

**结果。** PreC 系数明显回到接近原 Direct；ProbeC−PreC **−0.000364**，99又1/6% CI **[−.001976,+.001268]**；ProbeC−原 Direct **−0.000387**，CI **[−.002008,+.001199]**。ProbeC−DirectC +0.000562，CI [−.001669,+.002850]。

**判断。** 补偿了部分一般收缩，仍未释放要求的净迁移增量。不能说所有比较都排除了 .002，因为 ProbeC−DirectC 仍容许该幅度；停止依据是完整预设门失败。[报告](m6_student_compensation_results_20260915.md)

## 13. 第十二组：训练出口、直接适配与重复权重

### 13.1 已训练 H 的 mean6/CLS12 四格重读

**问题。** 先前全模型微调都从末层 CLS 监督，是否其实在第六层学到了未被读出的有用信息？

**设计。** 原 BGE/已训练 H×mean6/CLS12 四格；M6 复用，新增 15 个固定 λ=.001 头，不重训 encoder。H 已见过完整 own-fit 标签，因此不在其表示上做可能产生 encoder 内层泄漏的头部 CV。

**结果。** H6−原 M6 **−0.004059**，99又1/6% CI **[−.008474,+.000388]**；H6−H12 +0.002038，区间跨零；H6−Dense +0.000737，区间上界 .006554。

**判断。** 事后改读中间层没有恢复超过原 M6 的增量。两项存储 dtype 核查修订有记录，原结果不覆盖；不能把 dtype 检查中止当成模型阴性，也不能据此否定直接 mean6 训练。[报告](m6_trained_readout_results_20260915.md)

### 13.2 直接 M6 输出端适配：截至 9 月 17 日已完成

**设计。** 从同折原 M6 决策函数出发：A 更新 embeddings、前六层和头；C 只更新头；B 为不更新的原 M6。两臂相同批次、显式头正则、四 epoch；各在 cal 从 epoch0–4 选效用最高端点，十份选择全部冻结后统一 test。五折两臂十条轨迹、40 epoch、30,720 个逻辑训练步骤。

**干预确认。** 小试两臂各八步，A 的各目标模块实际更新，C encoder 不变，独立计算图重放一致。正式中断后，因 checkpoint 无 Adam 状态，重放 fold1 A 前 2,304 步并逐值核对后继续原预算；不是以空优化器接旧权重，也不是新增科学重复。

| 主比较 | F1 差 | 98.75% 条件区间 |
|---|---:|---|
| A−匹配 C | **−0.001026** | **[−.003258,+.001183]** |
| A−原 M6 B | −0.000379 | [−.002892,+.002057] |
| A−Dense | +0.004417 | [+.000018,+.008672] |
| A−BM25 | +0.032451 | 见原报告完整区间 |

A 选择 epoch [1,0,2,0,1]，C 选择 [0,0,1,0,1]。A 的 fit BCE 从约 .615–.628 降至 .170–.225，cal 终点却升至约 1.015–1.135。

**判断。** 直接监督实际决策出口显著提高拟合，但没有超过匹配头控制的必要增量；A−Dense 的旧池正区间不能替代 A−C 和独立验收。A−B 上界仍略高于 .002，不能统一说所有比较都排除 .002。当前固定四轮配方结束。[小试](m6_output_adaptation_pilot_results_20260915.md)、[正式完整报告](m6_output_adaptation_results_20260917.md)、[恢复规则](m6_output_adaptation_resume_plan_20260917.md)

### 13.3 重复答案权重诊断：已做诊断，未做新训练

**问题。** 原监督用 `abs(mean3 gap)`；若改为两个动作三次回答组成的九个差值逐个加权，会引入什么变化？

**设计。** 只在原五折 M6 的 own-fit 固定点计算，匹配损失单位并解析补偿正则尺度，区分额外 query 相关作用与归一引起的尺度变化。

**结果。** 总绝对权重比 ρ约 1.01245–1.01426；额外梯度与尺度梯度余弦约 .057–.121，局部 Hessian 度量下尺度比约 2.55–3.31。新增有向项仅在浮点/截断误差量级，主要附加作用可理解为针对重复分歧的对称置信度惩罚。

**判断。** 固定点的作用不只是正则缩放，也没有完全抵消；但九个差共享六个原回答，不是九个独立观测，未引入新的均值方向监督。**新训练数为零，没有 Router 增益结果。** 诊断归档，未自动推进 cross9 训练。[完整报告](m6_repeat_weight_diagnostic_results_20260917.md)

## 14. 哪些工作属于准备、复核，哪些尚未执行

### 14.1 已完成但不是额外科学效果实验

- 候选序列化、原始 query 接口重放、检索上下文构造、成本估算、collector 小试和账本完整性：使独立验证可以执行，不增加一份独立有效性证据。[早期候选核查](../../../work/router_research/candidate_independent_report.md)、[上下文核查](../../../work/router_research/contexts_independent_report.md)、[采集成本与小试](../../../work/router_research/collection_cost_and_smoke_report.md)
- 参数梯度、正规方程、独立求和及 bootstrap 复算：排除实现/数值错误；“独立 checker”通常为同一执行者另写的实现，不等于外部团队复现。
- 恢复实验和 checkpoint 重放：维持原实验身份，不增加科学重复。TLS/传输诊断解决采集故障，不是 Router 质量研究。
- 数学损失推导、文献定位和覆盖审计：构造或排除下一研究问题，不直接产生答案效用结果。

BEIR test 7,405 条中，236 条与历史组重叠，剩 7,169 条/7,158 groups。进一步历史审查发现，该来源曾用于检索政策和参数探索，包括 α 与预算等比较；**组不重叠并不能恢复来源未被使用的资格**。它对应原 HotpotQA 官方 dev，也不能因文件名 test 就当成新盲测。[组身份结果](m6_test_group_identity_results_20260915.md)、[选择历史审查](m6_test_selection_history_audit_20260915.md)

### 14.3 当前没有完成的事

1. cross9 重复目标的新模型训练与独立评价。
2. 能把 post-retrieval probe 优势稳定转成 pre-only 增量的新方法。

这些不能因已有设计、数学推导或脚本而登记为已取得研究成果。旧报告中的“下一步”“正在运行”是当时快照，后续正式终态和当前 registry 优先；本综述也没有把历史建议当作本次启动指令。

## 15. 全部证据合起来，研究认识到底推进了什么

### 15.1 可以支持的认识

| 认识 | 证据组合 | 适用范围 |
|---|---|---|
| 答案互补确实存在，但 query-only 可利用性有限 | 旧 oracle、E01、E08、M6独立验证 | 当前任务与配方；不是信息论不可能性 |
| 学会共同难度或辅助关系，不保证学会动作优势 | E09、共同量诊断、E14、G与支持迁移 | 已试的辅助目标与有限训练方案 |
| 充分拟合不能解决泛化 | E11C、全FT、LP→FT、直接M6适配 | 训练不足不是这些终点阴性的充分解释 |
| 来源、排序、阈值需要分开 | E03b、扩充M6、来源截距、固定偏移、两组四格诊断 | 有局部校准收益，但未确认扩充后的净增量 |
| 表示读取位置确实值得考虑 | E16/E17、层位×池化、M6与C12 | 内部方法选择证据，独立实际收益不足 |
| 检索状态有额外决策价值，迁移并不自动发生 | E04、匹配probe、严格Student、解析补偿 | post优势与pre收益之间仍有缺口 |
| 标签测量有边界问题，但尚非已证实的主瓶颈 | 重放、语义复评、judge校准、历史AC权重 | 未证明换指标就能改善训练 |
| 多次旧池阳性不能累积成新的独立确认 | 三次候选验证与来源审计 | 研究历史的核心证据边界 |

### 15.2 三次独立验证必须放在一起看

| 冻结对象 | 新 query 数 | 相对 Dense 的 F1 差 | 区间 | 验收结论 |
|---|---:|---:|---|---|
| E03b E1-old-cal | 4,000 | +0.002428 | 95% [−.002281,+.007069] | 未确认目标收益 |
| IDF 词项池化 I 平均 | 12,566 | −0.001538 | 97.5% [−.004320,+.001257] | 未确认目标收益及对 N 增量 |
| M6 | 5,209 | +0.003704 | 97.5% [−.001379,+.008972] | 未达到统计与 +.01 幅度标准 |

三次对象、采集方式、来源和比较数不同，不应直接合并成一个总显著性结果。它们共同约束当前研究叙述：不能凭旧池上的最好点值宣称稳定成功。

### 15.3 方法来源、实质成果与发表判断

当前实验大量使用既有工具和思想：Ridge/logistic、代价敏感学习、辅助监督、严格 OOF 蒸馏、关系表示学习、LP→FT、层池化、随机 Fourier 特征与校准。**使用和融合已有工作符合研究目标；不需要为了强调“独立”而否认这些来源。** 独立推进体现在提出竞争假设、构造匹配对照、执行实验和更新判断，不等于每个方法部件原创。

已有实质成果包括：可重放的数据与实验链、两代真正完成的特权迁移实验、有控制的中间层表示发现、匹配 probe 的信息增量、若干明确的失败机制与三次外部候选评价。它们是实际完成的研究工作，而非仅有构想。

但**尚未形成经过充分独立验证的改进方法，也不能据现有记录保证发表水准**。大量互相关联的旧池消融不等价于一个清楚、可推广的主结论；单个固定点梯度事实也不足以承担整篇改进论文。能否形成论文，取决于之后是否得到可识别的新增方法价值、足够强的对照、独立可重复效果及明确适用范围。不能把“发表负结果”擅自替代提升答案效用的原目标。[当前贡献评估与用户接受路线](research_contribution_review_20260917.md)

## 16. 暂停实验期间，下一步应如何准备

以下为建议顺序，**不是已启动实验**。

1. **先冻结一个可被推翻的改进命题。** 候选可以融合现有工作，但须说明它相对单部件、直接组合和强基线增加什么；明确哪些结果会否定假设，避免“任何小正值都算成功”。
2. **先解决独立评价资格和精度。** 逐一确认来源是否已用于筛选、分组是否泄漏、两动作效用能否取得、样本量能区分多大的效果。已有三批验证不再承担新策略的独立验收。
3. **再做有限的文献—实现—证据对照。** 区分哪些部件已有、哪些融合已做、哪里仍存在可检验缺口；不把已完成的全FT、early stopping、结构特征并集或校准重新包装成新方向。
4. **形成一个有界实验方案后再恢复执行。** 固定主比较、实用幅度、预算、停止规则；旧池只承担规定的开发角色，所有候选选择完成后才开启新验证。
5. **先回答泛化，再扩大方法复杂度。** 如果独立证据不能支持实用收益，调整任务假设、获取的信息或适用范围，而不是继续在旧池增加邻近实验。

这保留“融合已有工作以获得稳定显著提升”的路线，也直接回应当前最大的风险：下一轮必须增加一种新的、可推广的证据，不能只增加一个旧池表格。
