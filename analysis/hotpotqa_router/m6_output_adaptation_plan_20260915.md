# M6 训练出口直接适配：固定实验方案

日期：2026-09-15。遵循 [researcher.md](../../researcher.md) 的问题—假设—有区分力的实验—可信度检查—更新判断流程。该文件将与实现、输入一同绑定在 `protocol.json`；冻结后不改原方案。

## 1. 要减少的不确定性

原 M6 使用原始 BGE-small 第6层普通 token 均值，冻结表示、训练效用加权 BCE 线性头，旧池内部有较弱正向证据。后续 [H 读取视图对照](m6_trained_readout_results_20260915.md) 未发现现成最后层 CLS 微调模型改读第6层能够超过原 M6 的所需增量。

本轮问题：**从原 M6 的完整决策函数出发，让同一个答案效用目标直接作用于第6层均值，更新上游编码器，是否能在匹配的训练与选择控制之上提高答案收益？**

竞争性解释与预测：

| 解释 | 本轮可以观察的结果 |
|---|---|
| 训练出口与原有较好表示的起点很重要，直接适配能增加可泛化信号 | 允许表示更新的 A 同时超过原 M6 和匹配的仅更新头 C，达到预定增量 |
| 原表示上的头更新或校准集选择已足以产生差别 | A 相对 C 没有确认的净增量，不能把 A 相对原 M6 的变化都归给编码器 |
| 训练数据更易拟合，但新增变化不能泛化 | fit 损失下降，外层答案效用没有所需改善 |
| 初始函数、梯度或恢复实现不正确 | 小试不通过；先记录实现失败，不将其解释为科学负结果 |

这不是对 H 训练出口的严格单因素因果比较。它检验从原 M6 起点出发的一套固定适配与选择配方；A−C 隔离该配方中允许表示更新的条件增量。四轮阴性不能证明更长训练或所有 mean6 适配无效。

## 2. 数据与输入边界

- 仅用已经消费的旧9,600 query、9,559 group，以及原五个外层分组划分：每折 fit6144、cal1536、test1920。
- 两动作三重复平均答案 F1 为已有监督。令 `g=F1_BM25−F1_Dense`，`y=I(g>0)`，`w=|g|`（`|g|≤1e−12` 时权重为0）。不删除平局，不重新平衡类别。
- 模型只输入原 query 的固定128 token编码；无检索结果、probe、gold、支持文档或新答案输入。
- 梯度函数只接收自己 fit 的标签；cal 只用于下面预定的模型选择；正式 test 在全部模型选择冻结后统一执行。
- 旧池及 cal 已反复用于开发，区间不校正全部研究历史，不能作为独立来源确认。已验证5,209及 BEIR test 均不进入本轮政策效果评价。

## 3. 三个比较对象

| 名称 | 初始化 | 本轮可训练参数 |
|---|---|---|
| B | 原同折 M6 | 无，复用原 OOF 政策 |
| C | 原始 BGE＋原同折 M6 头 | 仅384D线性头的 weight/bias，共385参数 |
| A | 与 C 完全相同 | embeddings、第1—6个block及线性头，共22,565,761参数 |

模型实际保留前6个block、设 `num_hidden_layers=6`、去掉未使用pooler。取第6层普通有效 token（去padding和special，保留普通标点与停用词）的 FP32 均值；若没有普通token则回退CLS；L2归一化384D；原生 BF16 线性分数严格 `>0` 选BM25，否则Dense。

加载每折 `layer_pooling_v1/fold{f}_M6_head.pt`，**不能使用全9,600拟合的候选头**。原模型头五折均选中lambda=.001。两臂 optimizer state 均为空重新开始，不携带旧 Adam 状态。encoder 保持 `eval()` 关闭dropout，但 A 的梯度开启；pooling 不 detach。

## 4. 固定训练规则

每个批次目标为：

`mean_batch(w * BCEWithLogits(s,y)) / mean_own_fit(w) + .001 * ||head.weight||² / 2`。

- 分母是整个自身 fit 的固定平均权重，包含平局，不是当前batch权重和。
- 正则直接作用于 FP32 master head.weight，bias 不罚；每个批次都加入，包括全平局批次。
- 旧 H 的微调阶段没有保留 LP 的显式lambda，而使用 AdamW 衰减。本轮保留 M6 头目标是有意的新规则，不声称逐步重放 H 的目标。
- AdamW，betas=(.9,.999)、eps=1e−8、foreach=False；head lr=.001、head weight_decay=0。
- A encoder lr=2e−5、weight_decay=.01；bias及LayerNorm.weight不做decay。
- encoder与head分别clip gradient norm到1；保留clip前范数。C没有encoder更新。
- FP32 master/optimizer，BF16 autocast；batch8，max_length128。
- 固定4轮，每轮768步，每臂每折3072步；不按fit损失停止，不增轮、不重启seed。
- 第0起始步`s`的学习率倍数：设`t=s+1`；`t<307` 时 `t/307`，否则 `(3072−t)/(3072−307)`。最后一步学习率为0但仍记入步数；两臂使用同一计划。
- 每折 NumPy RNG `2026091517+fold`，每轮依次对自身全部6144条作permutation。两臂批次顺序相同；保留全平局batch，Adam动量、encoder decay或头正则仍可能产生更新。
- 五折A共5次encoder适配，C共5次仅头优化；合计30,720正式optimizer步骤，其中A为15,360步。小试模型不进入正式初始化。

## 5. 校准选择及一次外层评价

两臂各自在 epoch0、1、2、3、4 的五个端点中选择，使用自身cal的：

`mean_cal(g * I(native_BF16_logit > 0))`。

这等于相对固定Dense的cal答案效用差。选全局最大值；与全局最大值相差不超过1e−12的候选中取最早epoch。不得用链式近似平局更新。初始模型epoch0参加选择，动作阈值固定为0，不另拟合阈值。

选择次数及标签预算相同不等于没有选择乐观性；A−C比较的是各自经过同一有限选择规则后的整个配方。

所有10份选择及对应checkpoint先冻结，再统一对各自1920条test推理。全部OOF预测冻结后才计算政策效应。每轮fit/cal分数、完整候选、选择依据及最终test分数均保留。各分区报告的加权BCE用该分区自身权重和归一，与旧H部分fit-normalized诊断尺度区别开。

## 6. 主比较与继续条件

四个主比较：A−C、A−B、A−Dense、A−BM25。按group配对bootstrap20,000次，seed2026091519，按重采样query数作分母；四项Bonferroni名义家族95%，各区间98.75%，分位数[.00625,.99375]。

- 配方推进门：A−C和A−B均须点增益≥.002且区间下界>0。
- 候选准备门：上述门通过，且A相对两个固定动作均点增益≥.01、区间下界>0。
- 门未过则结束该固定四轮配方，不选择新层、新seed或根据test结果扩充epoch。
- 这些门仅决定是否值得准备独立确认；通过也不代表核心目标已实现。

固定描述项包括各折/合并F1、BM25次数、有益/有害切换及贡献、每轮fit/cal损失与收益、所选epoch、参数改变及实际资源。不把fold当作五次独立研究。

## 7. 先行小试与可信度验收

只用fold0的fit。两臂从原M6重置，执行正式首轮固定排列的前8批（64条），分母仍使用完整fit平均权重。恢复与特征检查固定使用 `fit[:64]`，这是复查集合，不等同于实际训练的64条。

验收：

1. 两臂初始完整6144条fit的特征与原M6原生分数精确重放，初始全部参数哈希相同。
2. 两臂相同的64条训练顺序、权重、学习率计划；所有loss/grad有限。
3. A的embeddings及6个block每个模块有非零梯度及实际更新，probe表示确实改变；保留每参数变化，不强求结构性零梯度参数或稀疏embedding每行都改变。
4. C encoder逐参数保持不变，表示精确不变；两臂头确实更新。
5. checkpoint恢复后的64条特征与分数精确重放。
6. 独立实现核查masked mean/L2及其梯度、首步损失/头梯度、原始12层模型第6层hook重放、实际8步优化重放及输入/产物绑定。独立检查预定两臂各64条初始推理、64条训练重放和64条终态推理，共384次完整12层query前向、16次optimizer重放步骤；这些属于同一小试的复现，不增加正式实验臂。

小试不计算新cal/test质量，也不据8步的拟合走向调整学习率、epoch或监督。实现失败保留原始异常；科学比较尚未开始。正式训练须等待小试独立复核通过。
