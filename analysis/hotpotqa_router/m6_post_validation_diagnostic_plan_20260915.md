# M6 完整验证后的最小机制诊断预案

日期：2026-09-15。状态：**仅预案，待正式主检验完成且账本与数值复核通过后执行**。这里不要求主效应通过统计或点幅度门槛，负面或不确定结果同样适用。本文件形成时，正式 `evaluation.json` 和 `evaluation_separate_checks.json` 均不存在；本次仅读取冻结动作、分数、身份、协议及既有报告，未读取当前 BEIR 答案、尝试响应或部分 F1。没有训练、API 调用或采集操作。

## 1. 要减少的不确定性

固定 M6 在新来源内部是否仍有分数与 BM25−Dense 效用的选择关联？若有关联，零阈值对应的动作位置是否合适？三次生成的差异是否使观察到的方向不稳定？

这是完成主检验后的解释性分析，不产生新策略或额外成功条件。既有扩充池的来源截距、固定系数偏移和排序×数量实验已经执行；本轮不重做它们、不拟合校准，也不扩大读取层或阈值搜索。将旧池分解用于新完整来源，是检查关联是否跨来源保留，不是独立证明某种语言机制。

## 3. 在效果未知时固定分组

令 `s` 为冻结 M6 原生 logit，`A=1[s>0]`。当前有 1135 条选择 BM25、4074 条选择 Dense，零分数为 0。只用分数定义两个切点：Dense 侧分数中位数 −0.4296875；BM25 侧分数中位数 +0.1611328125。相同分数保持同组，不拆开 BF16 并列。

| 固定组 | 分数范围 | query 数 | 含义 |
|---|---|---:|---|
| D_far | `s <= -0.4296875` | 2039 | Dense 侧较低分数 |
| D_near | `-0.4296875 < s <= 0` | 2035 | Dense 侧较接近零 |
| B_near | `0 < s <= 0.1611328125` | 568 | BM25 侧较接近零 |
| B_far | `s > 0.1611328125` | 567 | BM25 侧较高分数 |

“near/far”只指同一动作侧相对于零的距离，不表示校准后的置信度或正确概率。执行时重算并核对这四个数量；不因结果更换切点或合并表现不利的组。该分组允许分别观察两动作内部的分数高低关联，避免仅凭 BM25 总比例解释策略。

## 4. 仅输出三组诊断

### A. 四组中的分数与观测效用

令 `d_ir = F1(bm25,i,r) - F1(dense,i,r)`，`r=0,1,2`，`d_i` 为其三重复均值。四组均报告：query/group 数、平均冻结分数、组内平均 `d_i`、观测正/负/零 gap 数，以及两主比较对全体 5209 的贡献。判零沿用 `1e-12` 容差；效用值不因判零而截断。

明确区分两个分母：组内平均 gap 除以该组 query 数；组对总体策略差的贡献除以 5209。四组总体贡献之和须逐项复现正式主比较。

预定描述差只包括 `mean(d | D_near) - mean(d | D_far)` 和 `mean(d | B_far) - mean(d | B_near)`，并同时展示全部四组均值。若同一动作侧的高分组有较高实际 gap，这与来源内部排序关联保留相容；若零阈值两侧的平均 gap 与动作方向不符，则提示动作位置值得另行检验。粗分组、抽样差异及生成波动均可能产生此现象，不能据此认定某个新阈值会改善。

### B. 固定动作的效用分解

报告 `p=mean(A)`、`mu=mean(d)`，以及全部 5209 分母下的有益质量 `mean(A*max(d,0))`、有害质量 `mean(A*max(-d,0))` 和未选择 BM25 时放弃的正 gap 质量。

固定数量随机选择的解析期望为 `p*mu`；定义选择关联 `alignment = mean(A*d) - p*mu`。核对恒等式：

```text
M6 - Dense = p*mu + alignment
M6 - BM25  = alignment - (1-p)*mu
```

这区分整体固定动作优势、选择数量与具体 query 选择关联；随机量是解析期望，不执行随机策略，也不把超过随机选择当作超过强固定基线。它复用既有分解定义，不新增因果归因或显著性推断。

### C. 三重复的方向与幅度稳定性

对每个 `r`，在原全部 5209 分母下报告冻结 M6−Dense、M6−BM25 两个增益，并在上述四个固定组内报告平均 `d_ir`。同时列出三重复均值、三个单重复值的最小/最大值；不选择效果最好的重复，也不把三个重复当成三份独立 query 样本。

按 `1e-12` 容差将每条 query 的三个 gap 穷尽分为：全为零；非负且至少一次为正；非正且至少一次为负；同时出现正与负。报告四类数量及各冻结分数组内的比例；另报告 `max_r(d_ir)-min_r(d_ir)` 的中位数和 p90。零值、轻微浮点差异与真正跨零分别保留。

相同 repeat ID 只是调度配对，没有共享 provider 随机种子的保证。三次差异可以描述本次生成波动，不能精确估计长期噪声、证明服务端漂移或验证语义 Answer Correctness。F1 跨零也不自动意味着参考答案或评分错误。

## 5. 什么观察会改变下一步

| 完整主结果与诊断组合 | 优先下一步 | 仍不能得出的结论 |
|---|---|---|
| 原主门槛通过 | 固定 M6，优先做独立重复性与答案语义质量验证，再评估运行时集成 | 一次来源通过不证明稳定部署收益 |
| 主门槛未过，但同侧分数组保留正向关联、零附近方向不合适 | 为“位置变化而排序保留”提出独立验证问题；先盘点新来源，必要时将已消费数据用于开发匹配的固定系数研究 | 不能在本 BEIR 上挑阈值后继续称它为独立确认；普通校准此前已研究，不默认再做 |
| 主门槛未过，来源内部关联弱或方向不一致 | 优先检验表示与效用关系是否随来源/生成条件变化；使用有区分力的新来源设计，而非继续扩大 encoder 拟合 | 不能用当前分组不单调证明 query 输入原则上无信息 |
| 单重复结果变化明显、跨零 query 较多 | 优先制定独立的测量重复/语义评分研究，区分回答波动和真实动作差；资源另定 | 不能据3次重复直接归因于模型漂移，不能替换本轮主指标 |

上述方向可以同时出现，完整表格必须全部报告。不得根据单个有利分组选择路线并省略其他结果。未通过主门槛时，首先结合原区间区分“仍容纳 +0.01”“已排除 +0.01”与“有证据差于固定动作”，再解释机制线索。

本轮内部来源已消费；完整 BEIR 一旦被用于机制选择，也成为后续方法开发证据。任何新头、偏移或动作规则的成功主张仍需新的事先冻结评价，重新拆分同一批数据不能恢复独立性。
