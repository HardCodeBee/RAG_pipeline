## 2. 冻结设计与实际执行

| 政策 | 输入与训练 |
|---|---|
| L | 复用原 M6 线性头及原生分数，不重新拟合 |
| P | M6＋真实 probe，原效用加权 BCE |
| S0 | M6＋seed2026091506 的组置乱 probe，独立完整选参及拟合 |
| S1 | M6＋seed2026091507 的组置乱 probe，独立完整选参及拟合 |
| Dense / BM25 | 两个固定动作基线 |

每个 inner-training 与最终 fit 用全部对应训练行（含零 gap）计算 probe 均值及总体标准差；std≤1e−12列恒置0，其余标准化后除sqrt(50)，转FP32。P/S0/S1共享未置乱训练集的同一几何参数；验证、cal、test只应用该参数。保留原M6，不重新整体归一化。预测为434维加性线性头；CUDA BF16、batch8，M6支路有唯一bias、probe支路无bias，两个输出转FP32相加；分数>0选BM25。

各 inner-train、inner-valid、最终 fit、cal、test 分区分别置乱。按 group 行数分桶，以预定 SHA256 排序循环移位到另一个同大小 group，再按 query_id 配对组内行；只替换 probe，不移动 M6、标签、权重或身份。两控制不平均、不择优，均在训练和评价时置乱。控制保留 group 大小关联，并破坏 probe 与 M6 的联合对应；它不是给定 M6 的条件独立检验、因果识别或置换显著性检验。

损失标签为1[d>0]，权重为abs(d)×1[abs(d)>1e−12]，BCE除以权重和；加lambda/2乘全部434个系数平方和，截距不惩罚。每臂在原三个own-fit内折上比较五个lambda [.01,.001,.0001,.00001,.000001]，按全部内层验证原生分数的加权BCE选参，1e−12内同优选最强正则。cal只描述，不选阈值或模型。

冻结后真实 pilot 使用 fold0 fit 中最先128条全局单行group，P/S0/S1各在lambda=.001下拟合一次；三项均通过，另有480条原L的fit/cal/test零probe分数逐值重放，误差为0。正式每臂每折15个inner解＋1个refit，完成 **240次求解、15个最终头**；另计 **3次pilot**。全部头与fit/cal缓存固定并绑定后才生成全部9600条新外层预测，预测落盘后才计算效果。[pilot](../../outputs/router/hotpotqa_bd_router_v1/runs/m6_probe_readout_v1/pilot.json)、[拟合完成记录](../../outputs/router/hotpotqa_bd_router_v1/runs/m6_probe_readout_v1/fit_completion.json)、[预测冻结记录](../../outputs/router/hotpotqa_bd_router_v1/runs/m6_probe_readout_v1/predictions_frozen.json)

## 10. 下一步：仅进入严格OOF检索前Student的设计

本轮通过的是继续研究迁移的准备门。**截至本记录，尚未实施基于当前P/M6的新蒸馏或新Student训练。** 下一步应先把以下事项写成有界、可审阅的协议：

1. 明确Student允许的检索前输入、是否更新表示，以及Teacher目标的语义。效用加权BCE的logit/sigmoid不是原始F1 gap，不能直接当作已校准效用标签。
2. 在每个Student训练部分内部重新规定严格分组OOF Teacher目标生成，Teacher的拟合、标准化和选参均隔离外层cal/test；不得用当前全fit Teacher对同一fit的预测充当折外目标。
3. 设置直接真实效用监督和pre-only Teacher平滑控制，区分一般目标平滑与检索后信息迁移；目标混合、损失、停止及模型预算须预先固定，不因本轮正结果沿用未经论证的混合比例。
4. 先定义开发推进门及真正检索前预测的验收，再规划独立确认；当前P的内部增益不是Student的预期收益或成功保证。确认来源的身份和使用状态另见[来源库存](m6_confirmation_inventory_20260915.md)，本记录不据来源名称宣布新独立样本可用。

旧E04的蒸馏及其负结果仍有效约束当时62D Ridge、严格OOF和固定0.5混合配方；不能把后续工作描述为首次蒸馏，也不能因新的Teacher诊断为正就认定知识已转移。
