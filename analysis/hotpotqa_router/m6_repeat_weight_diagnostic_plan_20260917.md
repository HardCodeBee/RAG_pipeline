# 固定 M6 的重复权重作用诊断

2026-09-17。接续已完成且未过门的[M6输出直接适配](m6_output_adaptation_results_20260917.md)，依据[重复目标恒等式](repeat_objective_gap_note_20260915.md)。本方案在新的真实数据梯度计算前固定；仅诊断已有训练目标，不拟合新模型、不选择策略、不评价新的cal/test效果。

## 1. 问题与竞争解释

逐query先平均三重复F1差再加权BCE，与全部九个跨动作差值分别加权后平均，会怎样作用于当前原M6头？需要区分：附加作用主要来自目标归一改变正则尺度；重复构造产生额外的query相关置信度作用；单行作用在M6特征空间中大量抵消；数值／截断或身份错误制造了变化。E08已经分析整体生成噪声与跨重复互补，本轮不重复这些总体分析。

## 2. 数据与固定点

只用已核验E08旧9600的`repeats[N,2,3]`（动作顺序BM25、Dense）、原M6的query/group身份、384D冻结表示、五折own-fit索引和同折原头。原M6完整记录绑定头、特征、索引及lambda=.001。缓存须与E08检查收据绑定；输入资格核对三重复均值与原M6 utility、query/group顺序和组隔离。按query ID显式检查，不能只依赖行数。

所有新梯度、损失、曲率均只在对应的6,144条own-fit上计算。读取原utility仅用于监督身份核对；不读取原cal/test分数，不计算新策略或外层效果。五折fit相互重叠，不构成五次独立样本。使用保存头坐标转成FP64的理想目标，不声称重放实际BF16优化器。

## 3. 数学口径

令`d_rs=B_r-D_s`，`g=mean(B)-mean(D)`，`t(v)=v I(|v|>eps)`，eps=1e-12。定义`a=t(g)`、`b=mean_cross9(t(d))`、`c=mean_cross9(|t(d)|)`、`k=c-|a|`、`delta=b-a`。截断后k允许微负，不做clip。令`U=[X,1]`、`s=U theta`、`p=sigmoid(s)`、`h(s)=log(2cosh(s/2))`、`SA=sum|a|`、`SR=sum c`、`rho=SR/SA`。

原目标为`JA=sum |a| BCE(I(g>0),s)/SA + lambda ||beta||²/2`，bias不罚。重复目标各自归一时为`JR=sum mean_cross9(|t(d)| BCE(I(d>0),s))/SR + lambdaR ||beta||²/2`。

取解析补偿`lambdaR=lambda/rho`后，**把整个JR乘rho，转换到JA单位**，目标差为`sum(k h(s)-delta*s/2)/SA`；梯度差为`G=U^T[k(p-.5)-delta/2]/SA`。如果不补偿lambda，转换到JA单位后的差再增加`Gscale=lambda*(rho-1)*[beta,0]`。原归一目标的梯度需要另除rho，不能把换单位后的差直接称为`grad JR-grad JA`。截断后rho也可能小于1，因此只称正则尺度变化，不一律称正则增强。

另外保留浮点和截断的区别：`delta_num=mean_cross9(d)-g`；`delta_trunc=mean_cross9(t(d)-d)-(t(g)-g)`。有限精度下单独核验`delta≈delta_num+delta_trunc`，不把delta全称为截断影响。直接BCE与分解目标的loss、gradient、Hessian分别对照。

## 4. 预定输出

每折只输出以下固定项目，不做bootstrap或显著性检验：

1. 身份、分区、全部36种两动作重复编号排列的不变性；direct loss/gradient/Hessian分解误差及有限值检查。
2. SA、SR、rho、补偿lambda；k总量和范围、截断与浮点有向修正的范围。
3. 原目标驻点残差、原头正则梯度、原有向标签矩`U^T a/(2SA)`，以及附加梯度G、Gscale和两者之和的范数、方向及相对尺度。
4. 将k的偶对称项按互斥的“均值tie且cross9含正负”“非tie且cross9含正负”“其余”分解，另列delta_trunc和delta_num；保存各385D向量及逐行标量供独立复算。报告单行向量范数总和与合成向量范数之比，不能解释为可迁移信息比例。
5. 在固定原目标局部Hessian `HA=U^T diag(|a|/SA*p*(1-p)) U + lambda diag(I,0)` 下，报告最小／最大特征值、条件数，以及G、Gscale、原残差、正则梯度的`v^T HA^-1 v`和G／Gscale内积。它是当前点的局部尺度描述，不是目标重拟合、实际参数响应或收益预测。不构造新头、不应用局部位移、不选择新动作。

## 5. 可信度与停止条件

先通过合成检查：单方向差值、抵消tie、非tie方向翻转、近零截断、极端logit、无惩罚bias和编号置换。预定FP64代数误差绝对容差1e-11、相对容差1e-10；排列汇总误差绝对容差1e-12。原头驻点残差单独报告，若超过1e-7则先调查绑定或目标口径，不将其视为精确最优。局部HA须正定，Cholesky残差不超过1e-10；不为了得到结果添加jitter或删掉bias。

实施入口与本方案、输入摘要形成一个冻结protocol；结果保存后由另一实现复算核心量及全部五折。任何输入绑定或代数核查失败先停下处理实现，不解释为科学结果。五折固定输出结束即停止，不根据结果追加层、seed、阈值或答案调用。

梯度非零本身不构成训练推进门。完成后结合归一作用、方向抵消、驻点残差及局部曲率，判断是否出现值得另立匹配目标对照的问题；若要训练，需独立冻结方案与收益门槛。本诊断不能确认标签噪声主导、query信息不足、真实效用改善或独立来源收益。

另一个理论边界：忽略截断、正则和函数类限制，且两者条件权重都为正时，两种条件风险的有向项都由`E[g|X]`决定；各自无约束最优分数的符号相同，权重构造改变的是置信度尺度。零条件权重对应退化风险，不能要求唯一最优分数。有限维线性头和正则可以使实际动作边界不同，但不能将逐重复构造称为引入了新的有向标签信息。本轮局部梯度诊断也不证明任何重拟合后的边界更好。
