## 3. 研究已经推进到什么程度

### 3.1 历史基础：动作互补存在，但旧策略收益弱

在原 9600 条数据上，固定 Dense F1 为 0.648209，事后 BM25/Dense oracle 为 0.717565。两者之间的 +0.069356 是逐 query 动作互补空间，不是可部署收益。

Phase 2.7 M3 相对 Dense 仅 +0.002455，95% 区间跨零。winner-balanced 扩充的较大内部收益没有迁移为 natural2000 上的合格策略。207 个特质审计只留下一个较弱的 scope 关联，其加入 M3 后没有确认条件策略增量。9 月 10 日的新35D替换旧30D为 +0.000879，95% CI [−0.001380,+0.003178]。

依据：[历史综合报告](complete_research_report_20260901.md)、[Phase 2.11](phases/phase31/conclusion.md)。这些结果只约束当时的数据、表示与训练配方。

### 3.4 失败后进行了测量与表示机制研究

历史答案评分、上下文记录与 64-query 实际检索重跑通过核查；1000-query 同输入生成重测发现回答形式与重复波动会影响 F1 差值。语义评分及共享证据校准也实际做过，但未通过扩大为训练监督的操作门槛。不能把测量差异直接归因于已证实的服务端模型漂移。

文档偏好、支持文档监督 G、答案标签数量/获取机制、表示×读出、PLS、新35D与union、query关系监督及策略树等分支均已运行。G 相对匹配基线 A 有 +0.001860 内部增量，但 G−Dense +0.002402 的区间跨零。扩大到全层 encoder、LP 初始化后再微调也未通过各自完整门槛。

这些结果把问题推进到：**已有 encoder 的哪一层、哪种汇聚方式能提供可用于动作选择的表示，而不仅是继续增强训练拟合。**

依据：[测量重测](../../../work/router_research/generation_replay_results.md)、[支持监督](../../../work/router_research/support_encoder_results.md)、[全层微调](../../../work/router_research/encoder_scope_results.md)、[LP/FT](../../../work/router_research/lp_ft_v2_results.md)。

## 4. 当前候选 M6：是什么，有什么证据

推理流程：

> query 文本 → 冻结 BGE-small 前六层 → 普通有效 WordPiece 的 FP32 均值 → L2 归一化 384D → 线性头 → logit > 0 选 BM25，否则 Dense。

M6 不更新 encoder，不拼接旧30D/新35D，不使用 PCA/Ridge 或检索后输入。监督取自已有三重复答案 F1 差：符号为动作标签，绝对差为分类损失权重，tie 权重为零。训练正则在 own-fit 内部分组选择。

第6/12层 × CLS/普通token均值的四表示对照中，仅 M6 通过本轮候选门槛：

| 旧9600上的结果 | 数值 | 本轮调整后的 99⅙% 条件区间 |
|---|---:|---|
| M6−Dense | +0.004796 | [+0.000115,+0.009460] |
| M6−C12 | +0.006775 | [+0.001920,+0.011513] |

M6 平均 F1 为 0.653006；相对 Dense 五折四正一负。C12 是同一线性分类配方的最后层 CLS 对照，不是历史 M3。旧池反复用于研究，本轮六比较校正不覆盖全部历史选择，区间也不包含重训不确定性。

全旧9600拟合的 M6/C12 头已冻结；M6 在完整7885条扩充池上相对 Dense +0.049181、相对 C12 +0.031134，但相对固定 BM25 为 −0.006919，区间跨零，未通过迁移门槛。该池带有获取分层及标签配额选择，不能替代自然来源确认。

后续也已检验来源独立截距 S、扩充模型固定系数后的一参数偏移 P_C，均未通过各自完整门槛。P_C−Dense 为 +0.006286（条件99%区间 [+0.001389,+0.011246]），但相对旧 M6 和匹配校准对照的增量未确认。排序×选择数量的四格事后分解显示扩充排序在两个固定数量上的总体点值更好，逐折并不一致。因此不能把普通校准当成尚未尝试的新方向。依据：[固定系数偏移](../../../work/router_research/m6_pooled_offset_results.md)、[排序与数量](../../../work/router_research/m6_rank_count_diagnostic_results.md)。

六层推理类已在旧9600条上精确复现特征、logit 和动作。本机热启动单条请求中位耗时为 7.799ms，十二层参考为 13.079ms，约降低40.4%。这只是当前机器和固定执行路径的工程测量，尚未集成主运行时，也不提供独立答案效果证据。

依据：[层与池化](../../../work/router_research/layer_pooling_results.md)、[冻结候选](../../../work/router_research/m6_candidate_results.md)、[扩充迁移](../../../work/router_research/m6_expansion_transfer_results.md)、[六层实现](../../../work/router_research/m6_early_exit_results.md)。
