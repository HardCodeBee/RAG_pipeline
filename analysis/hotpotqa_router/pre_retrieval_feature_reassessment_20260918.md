# Pre-retrieval query特征再研究：能力、测量限制与证据边界

日期：2026-09-18。研究对象：固定HotpotQA语料、BM25/BGE、上下文与生成配置下，以最终答案效用选择BM25或Dense的检索前Router。

本轮完成历史代码/结果复核、原始论文核读，以及一次不读取query或标签的抽样概率与合成编码分析。没有新增模型训练、检索、答案调用或独立效果验证。历史结果来自已保存产物，不是本轮重跑。

## 1. 直接回答

**现有证据不支持“pre-retrieval特征从根本上无法满足Router训练要求”。但也没有证明我们已经找到足以带来稳定、显著、至少一个F1百分点收益的特征和训练方案。**

应当把“满足训练要求”分成三个问题：

| 问题 | 当前判断 | 根据 |
|---|---|---|
| 特征能否正确提取、对齐并用于训练？ | 能；已有完整训练与复现 | Phase2.11的9,600×35全部有限，无常量列，旧基线预测复现误差为0 |
| query及检索前语料信息是否包含可利用的动作选择信号？ | 有条件的内部证据支持，但不能外推为稳定总体规律 | E17剩余表示、M6与末层CLS的公平比较 |
| 现有方案是否达到研究要求的独立答案收益？ | 没有 | 三次不同冻结候选的独立验证均未达到目标 |

需要修正的是结论范围。`STOP_QUERY_ONLY_V1`关闭了当时的冻结候选和同类扩量，没有证明所有query表示、静态语料信息或训练方式都无效。另一方面，“还有未探索空间”也不能成为继续在旧池无限寻找局部收益的理由。

## 2. 先明确pre-retrieval到底包括什么

| 输入层次 | 本项目中的例子 | 边界 |
|---|---|---|
| 仅query文本 | 词数、问句形式、冻结query embedding、M6中间层池化 | 不访问当前问题的检索结果 |
| query＋预先冻结的语料统计 | 全语料DF/CF/IDF、全局原型、可离线构建的词项条件向量统计 | 语料信息不等于post-retrieval信息；线上查询和编码成本仍须计入 |
| query条件的未排序语料聚合 | 在固定50万文档样本中访问postings、计算scope与词对交集 | 旧Stage C把它归入主检索前；但它已有query条件匹配成本，不等同于纯查表 |
| 主检索后的观察 | 两动作Top-k、分数分布、文档重合、上下文覆盖 | 不可直接输入严格pre-only部署策略 |
| 答案或gold信息 | F1、EM、参考证据、正确动作标签 | 只可用于训练监督/评价，不能进入待预测问题的特征 |

因此，“query-only失败”和“所有pre-retrieval失败”不是同一结论。我们允许融合固定语料信息，但必须说明它在线究竟执行了什么，不能通过换名称把一次实际检索藏进特征提取。

当前环境保持不变：5,233,329个chunk、现有BM25索引与BGE-small文档向量、top50→5、无reranker、既定上下文与生成协议。新增Router特征可以使用这些固定产物，不更换检索器、语料或生成模型。主指标仍为三重复答案token-F1均值；它不是语义Answer Correctness。

## 3. 旧特征究竟测量了什么

### 3.1 原始30D＋384D

| 特征块 | 计算方法 | 特征意义 | 局限 |
|---|---|---|---|
| 17D词法统计 | BM25 analyzer处理query，再聚合词表覆盖率、IDF、logDF、低DF比例及数字/年份/大写/引号锚点的最大IDF | 描述词项稀有度与词表兼容性 | 标量聚合丢失具体词与统计值的对应、关系角色绑定；部分字段互补或共享来源 |
| 13D全局原型 | 10万语料向量聚为64中心，归一化后计算query相似度top1–8、margin、均值、标准差、熵和密度 | 描述query处于整体语义空间的什么位置 | 排序后的top值不保留中心身份；不描述某个实体词对应文档的语义分布；margin由top1/top2决定 |
| 384D冻结BGE | 使用冻结encoder获得query向量 | 保留比人工标量更丰富的文本表示 | 通用检索表示不必适合预测两动作最终答案差；读出层、池化和有限样本都会影响可利用程度 |
| PCA32读出 | 训练折内中心化、PCA，不白化，再与30D拼接成62D | 降低估计负担 | 按特征方差保留方向，不按动作效用；但后来完整384D实验未证明取消PCA就能解决问题 |

源码：[17D提取与13D原型](../../scripts/run_router_phase3_train.py)，[Phase2.7预处理与模型](../../scripts/run_router_phase27_model_audit.py)。

两个实现细节需要记住：第一，原17D对分析后的重复词计算统计，而实际BM25评分对query词去重；后来的unique版本才对应这个评分边界。第二，大写、关系、bridge等字段使用字符串规则，不是经过验证的实体识别或语义依存分析。例如关系提示包含后缀规则，comparison提示包含常见的“which”。它们是项目启发式，不能按字段名称就认定已提取完整关系结构。

这些局限针对相应特征块。完整embedding可能隐含词序或角色信息，不能因此声称整个414D输入必然没有这些信息。

### 3.2 207D、35D分别做过什么

**207D是单特征审计空间，不是已经联合训练并失败的207D Router。** Phase2.9明确不训练组合、交互或Router。筛查漏斗为207→139质量合格→25效应→18稳定shortlist→1最终支持。非显著的单字段仍可能参与有效交互；也可能确实没有增量，需要受限实验才能区分。

单字段最终支持的scope在natural上的AUC约0.58627、Spearman约0.08257；Phase2.10向M3追加scope的增益只有+0.000247，95%区间[−0.000141,+0.000662]，已消费natural附录中的策略增量为0。这只否定该固定追加配方的稳定增量。

**35D后来确实进入训练，不能再称“从未实验”。** Phase2.11将旧30D＋PCA32替换为新35D＋相同PCA32，固定Ridge α=10及折内校准。它不是完整旧特征加35个新字段：部分旧字段被替换，仅保留4个旧原型摘要。

这轮提取补齐3,806个缺缓存词项；2,760条重叠样本逐值一致；全部35列有变化，且没有非零率低于1%的列。因此，不支持“提取失败、大面积全零导致此次失败”的解释。后续还做过支持监督encoder下的新35D和新旧并集93D，均未确认所需增量。

## 5. 本轮新增发现：样本缺失与特征值的语义混合

### 5.1 50万文档样本对低频词不是充分观测

[Stage C实现](../../scripts/router_phase29_trait_features.py)从N=5,233,329个文档无放回均匀抽取m=500,000，覆盖9.554%。完整DF/CF是精确的；共现、部分scope、长度与标题统计来自样本。

若某词在完整语料出现于k个文档，抽样时完全没有覆盖它的概率为：

\[
P(K_{sample}=0\mid DF=k)
=\frac{\binom{N-k}{m}}{\binom Nm}
=\prod_{j=0}^{k-1}\frac{N-m-j}{N-j}.
\]

| 完整语料DF | 样本中完全缺失的概率 |
|---:|---:|
| 1 | 90.4459% |
| 2 | 81.8045% |
| 5 | 60.5262% |
| 10 | 36.6342% |
| 20 | 13.4206% |
| 50 | 0.6598% |
| 100 | 0.00435% |

这是抽取固定样本之前的概率，不是说每次调用固定索引会随机改变。它只刻画测量覆盖，不估计真实query中有多少词属于这些DF，也不证明低频词决定答案收益。

**实际含义：全语料中存在一个低频实体词，不保证样本里的共现字段能描述它。样本中未见不能解释成完整语料中不存在支持。** 这里没有否认精确DF字段本身的正确性。

### 5.2 新35D的两个共现坐标没有区分“未测到”与“测得零”

`_pair_values`遇到某词样本posting为空，会跳过该词对；没有可估计词对时，安全聚合返回0。207D原本还有`c_pair_estimable_ratio`，新35D只保留NPMI均值和零共现比例，没有保留可估计比例。

本轮直接调用原提取函数，构造8个合成文档的两个例子：

| 例子 | 两词的样本posting | NPMI均值 | 零共现比例 | 可估计比例（35D未保留） |
|---|---|---:|---:|---:|
| 某词没有样本支持 | 空集；{0,1,2,3} | 0 | 0 | 0 |
| 已观察到独立分布 | {0,1,2,3}；{0,1,4,5} | 0 | 0 | 1 |

第二例四个列联表单元均为2，原代码的0.5平滑后仍独立。两个保留坐标确实相同，但含义不同。

这证明的是**这个坐标块存在可避免的测量语义混合**。不证明整个35D相同；scope等其他字段可以区分或部分补偿，也没有证明它是现有失败的主要原因。`c_union_doc_length_log_ratio`在没有可用匹配文档时也用0，与实际平均长度等于全语料均值时的0共用编码，是类似的设计限制。

## 6. 理论上需要什么信息，而不是需要多少维

令固定环境下两动作的期望答案效用差为：

\[
\delta(q)=\mathbb E[U_B-U_D\mid q,C],\qquad X=\phi(q,C).
\]

使用X的最优路由规则在\(\mathbb E[\delta\mid X]>0\)时选BM25。相对固定Dense的最大期望增益是：

\[
G_X=\mathbb E\big[(\mathbb E[\delta\mid X])_+\big].
\]

相对最佳固定动作，应再减去\((\mathbb E\delta)_+\)。完整query的期望oracle为\(G_q=\mathbb E[\delta_+]\)，并且：

\[
G_q-G_X=\tfrac12\{\mathbb E|\delta|-\mathbb E|\mathbb E[\delta\mid X]|\}\ge0.
\]

直观上：如果压缩特征把“BM25能实质获益”和“Dense能实质获益”的问题混在一起，Router就会损失收益。**路由所需的是稳定区分有意义的优势方向，不要求完整预测答案，更不要求每个单字段都与赢家相关。**

固定语料和确定性检索规则后，检索结果是q、C的函数。post特征可能把压缩X丢掉、或有限模型难以恢复的信息显式计算出来；它优于某个pre模型，不证明完整query之外出现了独立随机信息。这里不包括gold、参考答案或尚未发生的生成随机性。

但“数学上存在query函数”不代表可以廉价算出。执行两次检索也能计算这个函数，却失去提前路由的成本目的。必须分别研究：表示损失、模型/计算约束、有限样本学习和来源迁移。

三个重复的经验oracle还包含“观察带噪声的两边均值后挑赢家”的乐观性：在无偏条件下\(\mathbb E[\hat\delta_+\mid q]\ge\delta(q)_+\)。旧池约+.069356经验headroom不等于pre模型必然可收回的收益。跨重复选择能减少这种乐观性，但仍是答案知情诊断。

上述是决策问题的基本推导，不作为新理论贡献。当前拟合模型失败只能评价该配方，不能给所有X模型的最优值建立上界。

## 7. 与已有论文的关系

| 原始研究 | 可以借鉴什么 | 不能代替什么 |
|---|---|---|
| [Arabzadeh等，2021：Sparse/Dense策略选择](https://arxiv.org/abs/2109.10739) | query-only分类器用于稀疏、稠密、混合策略选择；说明检索前选择不是概念上不可能 | MS MARCO检索效率/效果，不是当前HotpotQA最终答案F1验证 |
| [RouterRetriever，AAAI 2025](https://ojs.aaai.org/index.php/AAAI/article/view/33306) | 用query路由到不同领域检索专家，研究选择器与专家互补 | 专家集合与目标不同；BEIR nDCG收益不能移植成固定BM25/BGE答案收益 |
| [Can QPP Choose the Right Query Variant?，SIGIR 2026](https://arxiv.org/html/2604.22661v1) | 区分query难度相关性、同一信息需求的选择效用，以及检索指标与生成收益 | 研究对象是query变体选择，不能充当我们的二动作路由复现 |

因此，IDF、QPP、query encoder、蒸馏或专家路由本身都不是本研究的新颖点。允许融合已有工作；贡献必须落在明确的输入/训练机制、公平对照和可推广的最终效用增量上。本轮未建立新的可发表方法或新颖性结论。

| 假设 | 当前证据 | 决策 |
|---|---|---|
| 全部pre-retrieval输入没有任何可利用信号 | E17、M6等内部结果与这种笼统说法不符 | 不采用 |
| 已有提取存在粗压缩和测量可靠性缺失 | 源码与本轮合成分析支持；答案影响未知 | 作为输入设计必须处理的问题，不单独反复开训练 |
| 当前特征主要描述一般难度，缺少两动作差异所需的词法—语义对应 | 与旧标量/全局原型结构一致；仍是假设 | 优先一次有对照的机制实验 |
| 仅需更多维度、更复杂头或同类旧池扩量 | 完整384D、非线性、并集和扩量实验未支持简单解释 | 降低优先级，不重复网格 |
| 可学信号存在但幅度小，或跨来源不稳定 | 三次独立验证与此相容 | 必须保留为竞争性解释，不能用内部微增益回避 |

### 8.2 具体方法方向：保留词项与语料语义的对应，并显式记录测量支持

优先的问题是：**在同样query表示与计算预算下，保留词项条件的词法—Dense对应，是否比独立的IDF和全局语义摘要更有利于预测答案动作差？**

拟议输入由三部分组成：现有query表示；精确词项边际统计及明确的缺失/支持字段；预先离线构建的词项条件BM25加权Dense统计。它把已有词法方法和Dense几何融合，新增的是本项目旧输入未保留的对应关系，而不是宣称这些基础组件原创。

前轮已经完成32词、4,951条posting、4,950个现有文档向量的静态构建小试，以及“同矩但不同Top1”的反例。这只证明小规模构建可行、矩不是排名或答案充分统计量。**不能把它当作已成功的Router。** 详见[继续研究记录§8.28–8.29](research_contribution_review_20260917.md)。

在效果实验前还需固定：覆盖完整部署词表还是有界词表；单例/低频/高频词和未缓存词如何处理；哪些量可精确离线存储；线上query计算预算。当前文档向量的坐标属于实际Dense全模型，M6的中间层均值不能直接与它做有意义的同空间点积；若加入实际Dense query向量，所有比较臂都必须拥有同样输入并计入成本。

### 8.3 最小比较与停止规则

只考虑一个预先冻结的模型与三臂：

1. **边际基线**：相同query表示＋词法边际＋支持/缺失标记。
2. **真实对应**：基线＋真实词项条件词法—Dense配对量。
3. **对应破坏控制**：相同维度、支持与几何规模，但用预定变换破坏配对量和query坐标的对应。

该设计把“测量是否可用”在所有臂中统一，主问题集中在对应关系是否有增量。它不单独识别缺失标记的因果收益，不应事后将整体改进都归给掩码修正。控制的具体数学变换、训练来源、模型、校准、阈值、成本和样本量尚未冻结，本轮没有启动效果训练。

训练可复用明确标为训练资源的旧数据；不能再把旧池OOF当独立确认，304题上的候选搜索保持关闭。保留895题/750组未用于query读取、提取、选词、推理或标签采集。它们至多提供条件2Wiki来源的确认资源，是否有足够统计精度尚待协议确定，也不替代原HotpotQA确认。

效果必须同时比较最佳固定动作和输入匹配基线，主要终点为最终答案F1，保持原+.01实际幅度目标及预先规定的统计门，并报告延迟/存储。低相关性、内部正区间、较高动作准确率或Teacher拟合改善均不能代替这一终点。若真实对应不能超过边际与破坏控制，关闭该固定路线；若独立增益仍小或不稳定，接受边界结论，不继续改变矩阶数、中心数和词表阈值追逐旧池结果。

理论上，“post Teacher—压缩Student—完整query Student”的学习曲线能帮助区分表示与样本问题；但本项目已经执行过严格OOF迁移、表示微调和扩量。除非能明确指出新的训练分布与此前不同的可检验预测，否则不把重复蒸馏列为下一默认实验。

## 9. 本轮结论与状态

本轮实质增加了三点认识：修正了“有限候选失败＝pre特征不足”的推断；确认了旧62D并非已知query信号的完整表达；用现有提取函数给出了样本支持缺失与零值混用的具体证据。

**这些是可追溯的研究判断和输入设计约束，还不是答案质量提升，更不是已达到发表水准的正结果。** 当前最合理的立场是：pre-retrieval路由仍值得一次针对动作差异信息的受限研究，但举证责任已经提高——下一步必须证明输入机制带来独立净收益，不能再以旧池局部改进替代它。
