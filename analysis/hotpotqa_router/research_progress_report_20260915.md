## 2. 目标、输入时点与评价尺度

目标是学习 **query → BM25/Dense 动作**：在检索发生之前，根据问题文本和预先冻结的模型作出选择，提高最终答案质量。

- **部署输入：** query 及检索前已可用的信息。M6 的实际输入只有 query。
- **训练监督：** 可以使用两动作执行后产生的答案质量差；它是训练标签，不是部署输入。
- **检索后诊断：** 两路分数、文档交叠、上下文统计等必须先检索才能取得，不能直接作为本目标的线上输入。
- **主要质量指标：** 两动作各生成三次回答，计算 normalized-token answer F1，再取重复均值。F1 为 0—1；+0.01 是一个绝对 F1 百分点。
- **不同证据不能互换：** 检索召回率、答案 F1、语义 Answer Correctness 分别反映不同问题；事后 oracle 是已知两动作答案后的选择上界。

近期独立验证预定要求：相对两个固定动作的校正区间下界均大于零，且相对最佳固定动作的点增益至少 +0.01。内部配方的推进门槛另行冻结，不能代替这一标准。点增益达到 +0.01，也不等于已经证明真实收益至少 +0.01；后者需要相应区间下界支持。

## 3. 已经完成的研究链条

### 3.1 动作有互补性，早期 query-only 策略没有兑现足够收益

原 9,600 条数据上，Dense F1 为 0.648209，BM25 为 0.620175；逐 query 事后 oracle 为 0.717565。oracle 相对 Dense 的 +0.069356 说明两动作存在互补机会，但不说明 query 能预测这些机会。

[E08跨重复诊断](../../../work/router_research/e08_report.md)进一步用两次回答选动作、第三次回答评价，九种留出组合先在query内平均，得到相对Dense +0.064761，描述性95%区间[+0.060369,+0.069223]。这支持互补并非全部来自同一份答案标签上的选择和评价重用；该选择器仍使用答案标签，九种组合也不是九次独立研究，不能充当检索前策略收益。

## 4. M6 是什么，独立验证说明了什么

### 4.1 实际模型

> query → 冻结 BGE-small 第6层输出 → 普通有效 WordPiece 的 FP32 均值 → L2归一化384D → 效用加权 BCE 线性头 → 分数大于0选BM25，否则Dense。

M6 取第6层输出，不是把六层表示平均；不更新 encoder，不拼接旧结构特征，不使用检索后信息。训练动作标签是三重复平均 F1 差的符号，权重是差的绝对值，平局权重为零。该分数不是经过验证的“BM25 胜率”，也不能直接当作绝对期望 F1 增益排序。

在第6/12层 × CLS/普通token均值四表示对照中，M6−Dense 为 +0.004796，99⅙% 条件区间 [+0.000115,+0.009460]；M6−C12 为 +0.006775，区间 [+0.001920,+0.011513]，通过该轮内部候选门。旧池多次用于开发，该校正没有覆盖全部历史选择。

内部五折发现之后，候选阶段在完整旧9,600条上按预定的group内层验证重新选参并重拟合，M6与C12共完成32次求解，M6选中lambda=0.001。后续外部验证使用这一冻结候选头；它与内部OOF的五份头是不同模型实例。

冻结模型在完整 7,885 条扩充池上相对 Dense +0.049181，却相对 BM25 −0.006919、区间跨零，未通过最佳固定动作门槛。该池带有获取分层及胜负配额，不能解释为自然分布确认。来源截距和一参数偏移等校准也已实际做过，未通过各自完整门槛。

六层推理实现已在旧9,600条上精确重放特征、分数与动作。本机热启动单条中位耗时为7.799ms，十二层参考为13.079ms，约降低40.4%；这是局部推理测量，不是完整 RAG 延迟，也不是部署后的质量证据。依据：[候选](../../../work/router_research/m6_candidate_results.md)、[扩充迁移](../../../work/router_research/m6_expansion_transfer_results.md)、[六层重放](../../../work/router_research/m6_early_exit_results.md)。

## 5. 独立验证之后，七项受控实验与一次失败定位

七项实验均沿用已消费旧9,600条及原5个外层分组划分，每折 fit6144 / cal1536 / test1920。它们用于检验配方，不能算额外的独立来源验证；第5.5节为固定产物的描述性诊断，没有新拟合或显著性检验。

### 5.1 直接预测答案差，能否修复原读出？

固定 M6 表示，对照原效用加权 BCE 与直接 gap Ridge，并为两者施加相同的 cal 答案效用阈值选择。共80次正式 Ridge 求解、10个阈值选择，完成另一路数值复核。

| 主要比较 | F1 差 | 99% 条件区间 |
|---|---:|---|
| 原始阈值 Ridge−BCE | −0.001860 | [−0.004885,+0.001015] |
| 共同校准后 Ridge−BCE | −0.003024 | [−0.006459,+0.000390] |
| 校准 Ridge−Dense | +0.002472 | [−0.003153,+0.008121] |

当前配方没有达到预定增量。损失、平局参与及内层选参指标一同改变，不能把结果单独归因于某一项；区间跨零，也不能声称已经证明 Ridge 更差。依据：[完整 Ridge 结果](m6_objective_readout_results_20260915.md)。

### 5.2 增加固定非线性函数，能否提高动作收益？

保留原384D M6线性项，追加384D固定 sin/cos 随机 Fourier 特征；保留效用加权 BCE 与零动作边界。三个距离尺度只从相应训练部分确定；两个提前固定的种子各自训练，平均分数为唯一主政策 N，原线性政策为 L。没有根据结果改选单个种子或增加尺度。

正式160次求解、10个最终头全部完成并通过收敛检查；主运行约179.17秒，另一路检查约41.59秒。没有新增 encoder 前向、检索、答案生成或新 BEIR 政策评价，新增API费用为0。

| 主要比较 | F1 差 | 98⅓% 条件区间 |
|---|---:|---|
| 非线性 N−原线性 L | −0.000896 | [−0.003420,+0.001642] |
| N−Dense | +0.003900 | [−0.000681,+0.008524] |
| N−BM25 | +0.031935 | [+0.024384,+0.039496] |

**配方推进门与候选准备门均未通过。** 相对 L 的区间上界低于预定 +0.002 配方增量，相对 Dense 的上界低于 +0.01；以上排除幅度只在当前条件区间范围内成立，不能外推为所有非线性方法无效。

N 的 F1 为0.652109，原 L 为0.653006。N 共选择2,694次BM25，L为2,393次；N 的有益贡献从约0.021137增加至0.023982，但有害贡献幅度从0.016340增加至0.020082，增加得更多。切换更多没有带来净收益改善。

每折训练 BCE 都下降约0.0309—0.0324，说明新增函数实际参与拟合；外层 test BCE 三折改善、两折变差。训练损失下降未转化为足够动作收益，不能把两者当成同一个指标。

实现可信度方面，合成非线性正对照、真实小试及480条原头分数精确重放通过；160份解的独立完整梯度均低于预定1e−8门槛，另一路实现重算全部20,000次group bootstrap，主区间最大差约6.25e−17。复核未重跑全量GPU推理；“另一路数值实现”不等于独立样本或外部团队复现。

### 5.5 固定产物定位：额外监督是否进入了Student？

预先限定描述范围后，对相同线性软BCE建立精确关系：两臂目标之差仅通过`m=sum(w*(Q_b−Q_a)*[X,1])`作用于Student，损失差为`−theta^T m`；这里的w是当前fit内归一后、总和为1的效用权重。五折全部检查保留梯度残差的参数响应恒等式，没有求解新模型。这个m描述当前线性目标的有限样本作用，不能当作query总体信息量。

Probe−Pre的moment非零，beta差范数为.574—.681，外层分数变化RMS为.031262；199个query改变动作，其中24个改善、29个损害、146个效用持平。D→B的162条贡献−.000297，B→D的37条贡献−.000217，加总重放原−.000514。因此，模型确实收到并使用了目标变化，但这些动作变化没有形成净收益；“蒸馏根本没有生效”不足以解释结果。

另一方面，Pre头beta范数仅为Direct的.690—.725，Probe为.739—.770。用Direct自身FP64概率作参照，软目标moment可以精确分为四项：Direct自预测的正则收缩项、解的残余梯度、原生数值差异、OOF与完整拟合的预测差异。Pre实际moment与解析收缩项cosine为.877—.989，支持一般软化包含明显收缩。公共收缩项在Probe−Pre中消去，不能单独解释probe特有增量失败。

独立复核完成15项moment/响应、10个四向量分解、135个保存向量及全部动作贡献，1279项数值和数组检查最大差1.78e−15。跨折fit重叠，moment的方向一致不能当独立重复；归一化一阶关联不能当作解释方差或可迁移信息比例。[完整失败定位](m6_student_localization_results_20260915.md)

本轮只读取既有两动作各三次F1、原M6头及各折6,144条own-fit表示，核对cross9加权BCE与原目标的精确分解；不读取cal/test政策效果、不训练、不生成动作。五折归一比为1.01245—1.01426。统一目标尺度并补偿正则后，附加梯度与单纯尺度梯度的余弦为.0571—.1212，局部Hessian度量下的范数比为2.55—3.31。它说明当前固定点的额外作用不只是全局正则缩放，没有证明收益改善，也没有新增有向监督信息。

独立检查完成1,750项比较及180种重复编号排列；恒等式误差处于浮点尺度，所有检查通过。诊断5.65秒、复核14.97秒，无新API费用。九个差共享六份答案，不增加独立样本数；五折fit重叠。该诊断完成即归档，不因梯度非零自动启动cross9训练。[完整结果](m6_repeat_weight_diagnostic_results_20260917.md)

## 6. 当前证据支持什么，还不能回答什么

1. **动作互补真实存在，预测并利用它仍是难点。** oracle 空间不能自动转化成检索前可学收益。
2. **M6 中存在有限的内部路由信号。** 它值得进入过独立验证，但独立结果不足以支持预定的稳定收益目标；内部与外部点值接近也不能替代区间和门槛。
3. **当前两种读出补救没有成功。** 直接 gap Ridge 和这组固定 Fourier 扩展均结束；不能凭训练拟合改善就自动扩大模型、网格或种子。
4. **信息不足、有限样本估计、表示方式和动作边界的关系仍未唯一分开。** 现有结果没有证明 query 中完全缺少信号，也没有证明失败只有一个原因。
5. **检索后信息有内部价值，E04与M6蒸馏（含解析补偿）均未确认所需迁移。** 参数和动作已实际改变，一般收缩也经过单点干预；不能继续只以“未实施”“未收敛”或“共同收缩”解释probe增量失败。表示限制、Teacher估计误差、监督噪声与效用边界仍未唯一分开。
6. **中层重读和直接M6输出适配均未获得所需增量。** 后者已经实际更新上游表示，训练BCE大幅降低，但完整政策没有超过原M6或匹配控制的所需增量。这削弱了“仅把监督直接接到mean6即可解决当前问题”的固定配方解释，不能据此断言所有适配方法无效。

统计边界：本报告的交叉验证区间条件于已保存预测，不包含重新训练、重新选参以及全部历史研究选择的不确定性。按共享信息需求分组能防止同组泄漏，但五折不等于五次独立复制。对已消费旧池的后续检验始终属于开发证据。
