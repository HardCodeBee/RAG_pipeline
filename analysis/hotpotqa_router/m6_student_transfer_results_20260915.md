# 固定 M6：严格 OOF 软 BCE Student 迁移实验结果

2026-09-15。**45 次正式拟合完成，独立复核通过；固定配方的迁移门与候选准备门均未通过。** 本报告使用已消费的旧 9,600 query 开发池，记录一次已经实际执行的 Teacher→Student 蒸馏实验，不构成独立来源确认或部署结果。

## 1. 结论与决定

在相同 M6 输入、线性 Student、效用权重和固定正则下，加入 probe 的 Teacher 在五折自身 OOF 目标集上均有更低的硬标签 BCE；这一优势没有转化为达到预定幅度的 Student 答案 F1 增益。

- Probe Student−Pre Student：**−0.000513566**，99% 条件区间 **[−0.001734419, +0.000696801]**。
- Probe Student−Direct：**−0.000827846**，99% 条件区间 **[−0.002729756, +0.001082734]**。
- Probe Student−Dense：**+0.003968531**，99% 条件区间 **[−0.000448936, +0.008297978]**。

前两项区间上界都低于迁移门要求的 +0.002；第三项上界低于候选准备门要求的 +0.01。**在固定 OOF 预测和当前 group 抽样的条件推断范围内，结果排除了这些对应比较达到所要求的幅度。** 三个区间均跨零，不能据此认定 Probe Student 显著更差，也不能把结果外推为所有蒸馏都无效。

执行决定为 `END_FIXED_SOFT_BCE_STUDENT_RECIPE_NO_CONFIRMED_TRANSFER`：结束本次固定 α=.5、λ=.001、M6 线性 Student 配方，不自动追加 α、温度、阈值或正则网格。没有合格的新候选，核心研究目标尚未达到，运行时尚未集成该 Student。

原始数值见 [results.json](../../outputs/router/hotpotqa_bd_router_v1/runs/m6_student_transfer_v1/results.json)，终态复核见 [separate_checks.json](../../outputs/router/hotpotqa_bd_router_v1/runs/m6_student_transfer_v1/separate_checks.json)。原结果文件保留其生成时的 `pending_separate_check` 状态；后续复核收据的状态为 `passed_independent_student_transfer_checks`，不修改已绑定的原结果文件。

## 2. 研究问题、依据与实际设计

### 2.1 为什么执行本轮

此前的[匹配 probe 实验](m6_probe_readout_results_20260915.md)在相同 M6/BCE 条件下发现：需要检索后输入的 P 头相对原 M6 提升 +0.009581，并超过两份预先固定的组置乱控制，达到迁移研究准备门。该结果说明当前配方可以利用真实配对的 probe，尚不说明仅使用 query 的模型可以获得同样收益。

本轮问题是：**在严格排除目标组和外层保留组之后，用这些 Teacher 的软概率替代一部分监督，能否提高同一检索前 Student 的动作效用？** Pre Teacher 控制区分一般目标软化与新增 probe 的作用；Direct 保证比较的是净收益，避免仅因 Pre 变差便宣布迁移。

### 2.2 数据与输入边界

| 项目 | 本轮固定设置 |
|---|---|
| 数据 | 9,600 query、9,559 group；旧池已用于历史开发 |
| 外层划分 | 原五折，每折 fit 6,144 / cal 1,536 / test 1,920；每个 query 有一次外层 test 预测 |
| Teacher OOF | 各 Student outer-fit 内按原规则分为三份 group；每份 Teacher 用另两份训练 |
| Student 输入 | 冻结 384D M6 FP32：第 6 层有效普通 WordPiece 均值并做 L2 归一化 |
| Teacher 输入 | T_pre 为相同 M6；T_probe 为 M6 加原缓存 50D 检索后 probe |
| probe 处理 | 仅对应 Teacher 的训练全部行估计均值/总体标准差；标准化后除 sqrt(50)，转 FP32；近零标准差列归零 |
| 答案效用 | 两动作各三次回答的 normalized-token F1 均值；本轮没有新生成回答或语义 Answer Correctness 评价 |
| 参数与动作 | 所有 Teacher/Student λ=.001，混合 α=.5；原生 logit>0 选 BM25，否则选 Dense |
| cal 的用途 | 只记录保留集 BCE，不参与训练、Teacher 目标生成、选参或阈值确定 |
| 新调用 | 0 encoder forward、0 检索、0 生成回答、0 外部 API |

probe 只从原文件加载 `probe/query_ids/group_ids`。其字段 schema 不使用 qrels 或生成质量；同一缓存文件还包含其他 gold 块，本轮没有加载这些块，也不宣称原缓存的整个制备流程都不接触 gold。

λ=.001 的依据来自已消费的原 M6 五头和匹配 probe 十五头的开发选择。本轮没有再搜索参数；预先固定这些参数不会恢复旧池的独立性。完整设置见[冻结方案](m6_student_transfer_plan_20260915.md)和[协议](../../outputs/router/hotpotqa_bd_router_v1/runs/m6_student_transfer_v1/protocol.json)。

### 2.3 三臂监督与损失

令 d=F1(BM25)−F1(Dense)，Y=1[d>0]，W=abs(d)×1[abs(d)>1e−12]。

| Student 名称 | 训练目标 Q | 推理时输入 |
|---|---|---|
| Direct | Y | 仅 M6 |
| Pre | .5Y+.5sigmoid(T_pre OOF 原生 logit) | 仅 M6 |
| Probe | .5Y+.5sigmoid(T_probe OOF 原生 logit) | 仅 M6 |

本报告中的 **Probe Student 仍是检索前模型**；需要检索后输入的是 T_probe，以及上一轮的诊断头 P，三者不能混称。

Teacher 的每个目标都来自排除该目标所属 group 的训练。Teacher 的训练也排除相应 Student 的 cal/test；probe 几何仅由它自身训练集估计。没有复用上一轮 P 的全局 OOF 预测，也没有在 Student 内层重新选参。每折的 6 个 Teacher 产生覆盖全部 6,144 个 fit query 各一次的两类目标，再拟合 3 个 Student；合计 **30 个 Teacher、15 个 Student、45 次正式拟合**。

Teacher 原生 FP32 logit 转 FP64 后取 sigmoid，不使用温度、概率截断或校准。Student 用原 W 归一和未惩罚截距，数据损失为加权平均的稳定软 BCE：

$$
\ell(Q,s)=Q\log(1+e^{-s})+(1-Q)\log(1+e^s),
$$

并加入 λ‖β‖²/2。实现使用 `logaddexp`，没有将软目标代入仅适用于二值标签的 signed-softplus。Direct 和硬 Teacher 调用原 refined solver。

**Teacher 概率或 logit 不是 F1 gap。** 理想效用加权 Teacher 给出 E[WY|Z]/E[W|Z]；正负效用质量分别为 a、b 时，其概率为 a/(a+b)，而期望 gap 为 a−b。保持原 W 的软 BCE 在理想 Teacher 下与原检索前总体目标一致，但有限 Teacher 的估计误差可以有利也可以有害；本轮负结果不否定该总体等式。[目标推导](m6_distillation_rationale_20260915.md)

两个描述性的贡献分解帮助理解净值：

- Probe 相对 Direct 少选 279 次 BM25。有益质量减少 **0.002831185**，有害质量也减少 **0.002003339**；两者相减得到净变化 **−0.000827846**。减少切换同时减少了收益与损害，不能只用切换数下降解释质量。

这是已有固定策略的算术分解，不是新增显著性检验，也不将策略间净切换数当成两者动作不同的 query 总数。

## 4. 五项预先固定的主比较与门槛

共享 20,000 次 group bootstrap，seed=2026091509；每次有放回抽取 9,559 个 group，按实际抽中的 query 总数归一。五项使用双侧 99% 区间，即 [.005,.995] 分位数，对应五项名义 Bonferroni 家族。

| 主比较 | 配对 F1 差 | 99% 条件区间 | 对预定问题的回答 |
|---|---:|---|---|
| Pre−Direct | −0.000314280 | [−0.002272841, +0.001677499] | 未确认一般软化收益 |
| Probe−Pre | −0.000513566 | [−0.001734419, +0.000696801] | 未达到新增 probe 的迁移门；上界低于 +0.002 |
| Probe−Direct | −0.000827846 | [−0.002729756, +0.001082734] | 未达到净迁移门；上界低于 +0.002 |
| Probe−Dense | +0.003968531 | [−0.000448936, +0.008297978] | 未确认超过 Dense；上界低于候选要求的 +0.01 |
| Probe−BM25 | +0.032002928 | [+0.023380269, +0.040507895] | 超过固定 BM25，但不足以满足双固定基线要求 |

迁移门要求 Probe−Pre 和 Probe−Direct **都**满足点值≥.002 且下界>0，实际为 **false**。候选准备门还要求 Probe 对 Dense 和 BM25 **都**满足点值≥.01 且下界>0，实际也为 **false**。

这些区间条件于已固定的 OOF 预测和当前 group 抽样，不包含重新拟合、Teacher 估计、全部历史开发选择或新来源的不确定性。因此“上界低于门槛”是有明确条件的幅度排除，不是分布无关的上界，也不是蒸馏普遍不可能的证明。样本量没有按本轮效应扩充，没有追加其他区间或阈值搜索。

## 8. 独立复核结果与证据边界

独立 checker 不导入新运行器或软数学模块，不重新拟合，也不重新调用 GPU。北京时间 **17:10:32** 生成通过收据，核对包括：

- 11 项源绑定、20 项输入绑定；5 次小试和全部 45 条正式解与 journal 一致。
- 15 份 Teacher 训练几何、92,160 行正式 probe 变换缓存、30,720 个严格 outer-fit OOF 目标和 15 份目标组排除关系。
- 30 个硬 Teacher、5 个硬 Direct、10 个软 Student 的目标值和完整梯度；最大独立梯度 **5.558284320e−9**，均低于 1e−8。

- 全部 20,000 次 bootstrap 抽样结果；最大独立数值差 **2.22e−16**。

对保存的新原生分数，checker 用 CPU 上的 BF16 操作数舍入、FP64 中心值和 FP32 累积/最终舍入误差界，检查其与对应头和输入一致：**77 个向量、205,568 行**通过；最大中心偏差 0.008512，记录的最大允许界为 0.017585。这个检查不是独立 GPU 逐值重放，也不证明任意替代 CUDA 内核都给出相同输出。小试 Student 的即时原生分数只在源绑定运行器中做过有限性检查，没有保存；checker 对这些小试核对头和目标，不声称复核了未保存的分数。

| cal/决策 | cal 用真实 F1 做仿射校准 | cal 仅诊断，原生零边界固定 |
| 正式规模 | 75 个 Teacher、20 个 Student | 30 个 Teacher、15 个 Student |
| 特权增量 | S_probe−S_pre=−0.000087，98⅓% 区间跨零 | Probe−Pre=−0.000513566，99% 区间跨零且上界低于 .002 |

两轮不构成只改变一个因素的直接比较。旧 E04 的负结果仍约束其 62D Ridge 混合回归配方；本轮新增的约束是：**已有匹配 M6/probe 诊断增量、同一 Student 表示与线性类、与原效用目标一致的软 BCE、严格内部 OOF 和固定参数，仍未获得要求的迁移收益。** 不能再仅用“旧 Student 表示不同”或“把 BCE Teacher 概率误当 F1 gap”解释本轮结果。

竞争假设的更新是：

1. **当前配方可获得至少 .002 净迁移和 probe 特有增量的预期下降。** 两项对应条件区间上界均低于该幅度；一般 Pre 软化也没有确认收益。
2. **检索后 probe 在当前 Teacher 中有用这一事实没有被否定。** 本轮五折 Teacher OOF BCE 较低，与上一轮匹配 probe 的答案效果是不同但相容的证据。
3. **Teacher 的可用信息与 Student 能实现的收益仍有区别。** 可能涉及仅使用 M6 时不可预测的成分、线性 Student 的投影限制、有限 Teacher 误差和固定决策边界附近的变化；现有结果尚不能把它们分别归因。
4. **这次结果已有数值与数据隔离核验支持。** 不能把通过验收的阴性结果等同于未收敛；同时审计不能消除已消费数据和条件区间的推断限制。

## 10. 后续研究边界

本次固定配方到此结束。下一步优先准备一个有界的失败定位问题：**T_probe 相对 T_pre 在连续监督上的改善，有多少进入了 M6 Student 的分数，又有多少体现在固定零边界附近的动作与原始效用贡献中？** 应先固定描述范围，使用已有缓存定位误差；不得据结果追选新阈值、α 或 query 子集来宣布改进。当前报告没有执行这一新诊断。
